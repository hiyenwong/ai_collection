# Thermodynamic Networks: Harnessing Non-Equilibrium Steady States for Computation

> A framework for physical computation using thermodynamic networks that harness non-equilibrium steady states to perform computational tasks, bridging thermodynamics and computer science.

## Metadata
- **Source**: arXiv:2605.15985
- **Authors**: Patryk Lipka-Bartosik, Gianmichele Blasi, Javier Lalueza Puértolas, Géraldine Haack, Martí Perarnau-Llobet, Nicolas Brunner
- **Published**: 2026-05-18
- **Cross-domain**: Quantum Physics (quant-ph) + Thermodynamics + Computation

## Core Methodology

### Key Innovation
Maps computational problems to **non-equilibrium steady states** of thermodynamic networks, where computation emerges naturally from the system's thermodynamic evolution toward its steady state. This provides a fundamentally different computational paradigm from standard digital or quantum computing.

### Technical Framework

1. **Thermodynamic Network Design**
   - Construct networks with specific energy landscapes
   - Design coupling strengths to encode computational problems
   - Map input/output to thermodynamic variables

2. **Non-Equilibrium Steady State Computation**
   - System evolves toward steady state under driving forces
   - Steady state encodes solution to computational problem
   - Dissipation is not a bug but a feature — drives computation

3. **Energy Flow as Computation**
   - Energy currents through network perform logical operations
   - Heat dissipation bounds computational accuracy
   - Trade-off between speed, accuracy, and energy cost

4. **Physical Implementation**
   - Realizable with various physical platforms
   - Electronic circuits, quantum dots, molecular machines
   - Naturally parallel and energy-efficient

## Implementation Guide

### Prerequisites
- Non-equilibrium thermodynamics
- Master equation / Lindblad formalism
- Statistical mechanics of open systems

### Design Steps
1. **Problem Mapping**: Encode computational problem in network topology
2. **Parameter Tuning**: Set energy levels and coupling strengths
3. **Steady State Analysis**: Compute system steady state
4. **Readout Protocol**: Extract solution from steady state distribution
5. **Performance Analysis**: Evaluate speed, accuracy, energy cost

### Key Trade-offs
- **Speed vs Accuracy**: Faster computation requires higher energy cost
- **Dissipation vs Reliability**: More dissipation can improve accuracy
- **Network Size vs Complexity**: Larger networks handle harder problems

## Applications
- Energy-efficient computing
- Physical neural network implementations
- Molecular computation
- Thermodynamic logic gates

## Pitfalls
- Requires careful thermal management
- Steady state convergence time can be long
- Readout precision limited by thermal fluctuations
- Scaling to complex problems requires careful network design
