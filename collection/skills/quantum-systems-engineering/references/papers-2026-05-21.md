# Systems Engineering + Quantum Research: 2026-05-21

## Paper 1: Quantum RL for Process Synthesis (arXiv:2605.21213)

**Title**: Enhanced Reinforcement Learning-based Process Synthesis via Quantum Computing
**Authors**: Braniff, You & Tian (WVU, Cornell)

### Key Contribution
State encoding algorithm that **decouples qubit requirements from problem size** — the central scalability bottleneck in quantum RL for engineering design.

### Methodology
1. Reformulate process synthesis as MDP (state = partial flowsheet, action = add/remove unit, reward = economic metric)
2. Encode states via compressed representation → fixed qubit count regardless of design space size
3. Three quantum RL variants: circuit RL, quantum-enhanced value functions, hybrid quantum-classical
4. Benchmark against classical RL under identical training conditions

### Results
- Small design spaces: all approaches find optimal solutions
- Moderate scale: quantum competitive per-episode, **superior per-parameter efficiency**
- Scalability limited by qubit count — state encoding is the key enabler

### Reusable Pattern
```
Process Synthesis → MDP → Compressed State Encoding → Quantum RL → Benchmark vs Classical
```

## Paper 2: Pulse-Level QML Software Framework (arXiv:2605.21286)

**Title**: Software Between Quantum and Machine Learning -- And Down to Pulses
**Authors**: Franz, Strobl, Hunz, Scheller, van der Horst, Kuehn, Streit, Mauerer

### Key Contribution
Software framework integrating **quantum optimal control within QML** for pulse-level modelling, bridging gate-based abstractions with hardware-aware optimization.

### Architecture
- **QML-Essentials package**: unified gate + pulse representation
- **Composable ansatz**: interchangeable building blocks (gate layers, pulse layers, hybrid)
- **End-to-end optimization**: JAX-based automatic differentiation through pulse parameters
- **Fourier diagnostics**: spectral analysis for expressivity, entanglement measures

### Reusable Pattern
```
Gate-level circuit → Pulse-level refinement → Composable ansatz → JAX optimization → Fourier analysis
```

### Practical Insight
Start with gate-level abstraction for correctness, then refine at pulse level for hardware-aware performance. Fourier analysis provides the diagnostic bridge between the two levels.
