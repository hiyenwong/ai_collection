# 梦境认知模拟器 (Dream Cognitive Simulator)

基于神经科学和认知心理学研究的梦境生成模拟系统。

## 核心理论基础

### 1. 记忆巩固理论 (Memory Consolidation)
- **来源**: Qi Zhang (2026) "A computational account of dreaming"
- **机制**: 梦境帮助将短期记忆转化为长期记忆
- **过程**: 白天经历 → 海马体索引 → 皮层重放 → 记忆整合

### 2. 神经动力学模型 (Neuro-Dynamic Model)
- **来源**: Tavangari et al. (2025) "A Neuro-Dynamic Mathematical Model"
- **机制**: 自发认知活动的数学建模
- **特征**: 神经元的随机激活模式形成梦境叙事

### 3. REM睡眠机制
- **来源**: Akhavan et al. (2026) "Data-Driven Measure of REM Sleep Propensity"
- **特征**: 快速眼动期的高活跃度、情感处理、记忆整合

### 4. 情感耦合理论 (Affect Coupling)
- **来源**: Leckie et al. (2024) "The content and structure of dreams are coupled to affect"
- **机制**: 日间情感体验影响梦境内容

## 梦境生成流程

### Phase 1: 输入收集 (Encoding)
- 收集用户提供的日间经历
- 识别关键事件和情感标记
- 建立记忆线索索引

### Phase 2: 记忆激活 (Consolidation)
- 随机激活相关记忆片段
- 应用神经动力学权重
- 形成记忆片段的关联网络

### Phase 3: 叙事构建 (Narrative Construction)
- 将记忆片段编织成叙事
- 应用梦境逻辑（时间/空间跳跃）
- 注入情感色彩和象征元素

### Phase 4: REM特征增强 (REM Enhancement)
- 增强视觉和情感元素
- 添加超现实转换
- 激活隐喻和象征系统

### Phase 5: 输出呈现 (Dream Report)
- 生成梦境报告
- 提供神经科学解释
- 建议觉醒后的反思

## 梦境元素库

### 常见梦境主题
- **坠落**: 失控感、焦虑
- **飞翔**: 自由、超越限制
- **追逐**: 逃避、未解决的问题
- **迷路**: 方向感缺失、探索
- **考试**: 压力、自我评估
- **牙齿脱落**: 无力感、形象焦虑

### 情感-梦境映射
| 日间情感 | 常见梦境表现 |
|---------|-------------|
| 焦虑 | 追逐、迟到、考试 |
| 喜悦 | 飞翔、明亮场景、庆祝 |
| 愤怒 | 战斗、破坏、风暴 |
| 悲伤 | 失去、离别、阴暗 |
| 好奇 | 探索、发现、迷宫 |


### 神经网络模型

基于 Tavangari et al. (2025) 的神经动力学模型:

```
梦境生成 = f(记忆激活, 情感状态, 随机噪声, REM特征)

其中:
- 记忆激活 ~ Poisson过程(λ=日间经历权重)
- 情感状态 ~ 杏仁核活动水平
- 随机噪声 ~ 皮层自发活动
- REM特征 ~ 脑干激活模式
```
