# Representation Use and Usability Framework

## Overview

A cross-disciplinary framework unifying how **representation** is conceptualized across philosophy, neuroscience, cognitive science, and computer science. Introduces the critical distinction between **use** and **usability** of representations.

**arXiv**: 2604.13829 | **Published**: April 2026

## Core Concepts

### Use vs Usability Distinction
- **Use**: How a representation is actually employed in a system or organism
- **Usability**: The potential of a representation to be used — its inherent properties that enable or constrain use

### Why This Matters
Different fields use "representation" with incompatible assumptions:
- **Philosophy**: Intentional content, aboutness, semantic properties
- **Neuroscience**: Neural coding patterns, population activity structure
- **Cognitive Science**: Mental models, symbolic structures
- **Computer Science**: Data structures, embeddings, latent spaces

## The Framework

### Three Dimensions
1. **Structural**: Format, dimensionality, organization of the representation
2. **Functional**: What computations the representation enables
3. **Interpretive**: How the representation maps to what it represents

### Cross-Field Mapping
| Field | Primary Focus | Representation Type |
|-------|--------------|-------------------|
| Philosophy | Aboutness, intentionality | Conceptual/semantic |
| Neuroscience | Neural activity patterns | Distributed population codes |
| Cognitive Science | Mental processes | Symbolic/subsymbolic |
| Computer Science | Data processing | Embeddings/vectors |

## Practical Applications

### For AI Research
- Evaluate whether neural network representations have genuine **usability** for downstream tasks
- Distinguish between representations that merely correlate with outputs vs. those that enable flexible use

### For Neuroscience
- Bridge the gap between neural coding studies and philosophical accounts of representation
- Formalize when neural activity counts as "representational" vs. merely causal

### For Cognitive Science
- Unify debates about format of mental representation (symbolic vs. distributed)
- Clarify what makes a representation "good" — not just accurate, but **usable**

## Key Insights

1. **Use is necessary but not sufficient for usability** — a system can use a representation without the representation being flexibly usable
2. **Usability is a relational property** — depends on the relationship between representation format and user capabilities
3. **Cross-field communication fails** when one field's "use" is another field's "non-representation"
