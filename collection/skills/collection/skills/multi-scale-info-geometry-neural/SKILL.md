# Multi-Scale Information Geometry for Neural Population Dynamics

## Overview
This paper develops a mathematical framework combining information geometry, coarse-graining, and Fisher information metrics to analyze neural population dynamics across multiple spatial and temporal scales. It bridges the gap between microscopic single-neuron activity and macroscopic population-level descriptions.

**arXiv**: 2605.06304 (May 2026)

## Core Methodology

### Information Geometry Framework
- Models neural population activity as points on a statistical manifold
- Uses **Fisher information metric** to define distances between neural states
- Provides a geometric characterization of neural coding efficiency

### Coarse-Graining Process
- Systematic reduction from fine-grained (single neuron) to coarse-grained (population) descriptions
- Preserves essential dynamical features while reducing dimensionality
- Enables analysis at multiple organizational scales

### Fisher Metric Extension
- Extends Fisher information to capture higher-order correlations
- Quantifies how information is distributed across neural populations
- Relates geometric structure to functional connectivity patterns

## Key Contributions

1. **Geometric Characterization**: Neural states as points on manifolds with well-defined metrics
2. **Scale Bridging**: Mathematical formalism connecting micro and macro descriptions
3. **Information Preservation**: Quantifies how coarse-graining affects representational capacity
4. **Dynamical Analysis**: Applies geometric tools to study neural population dynamics
