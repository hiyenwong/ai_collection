# EPIC: Rethinking Trust Regions for Autoregressive LLM Policies via Exact-KL Prefix Importance-Ratio Clipping

## Key Contribution
Identifies a fundamental mismatch in PPO-style clipping for autoregressive LLM policies: standard token-level clipping measures policy change only through conditional probability of the current token, but the prefix conditioning context is itself generated by the policy. Proposes EPIC with exact-KL prefix importance-ratio clipping.

## Core Method
- **Problem**: In autoregressive LLMs, the "state" (prefix) is generated by the policy itself. Standard PPO clipping only looks at per-token probability ratios, ignoring that the prefix distribution has also shifted.
- **Consequence**: Trust region is incorrectly measured → policy can drift far in sequence-level distribution while appearing close in token-level ratio
- **Solution (EPIC)**: Compute importance ratios over entire prefix sequences, not just single tokens. Use exact KL divergence over the prefix to properly constrain policy updates.
- **Integration**: Drop-in replacement for PPO clipping in RLHF/GRPO pipelines

## Why It Matters
- Fixes a subtle but important bug in how RLHF/GRPO measures policy trust regions for LLMs
- Directly applicable to anyone doing PPO-based LLM alignment or reasoning training
- Explains instability modes in long-generation RLHF where token-level KL looks fine but sequence-level quality degrades
- Compatible with existing RLHF frameworks (TRL, OpenRLHF, etc.)

## Application Scenarios
- RLHF training pipelines for LLM reasoning
- GRPO-based training (e.g., DeepSeek-R1 style)
- Any PPO-style LLM fine-tuning where generation length > 100 tokens
- Diagnosing training instability in reasoning model training

## Implementation Notes
- Prefix importance ratios require caching log-probs for the full prefix, not just current token
- Computational overhead is manageable with KV-cache (prefix log-probs already computed during generation)
- KL computation uses exact prefix distributions, not Monte Carlo estimates
- Recommended clip range: similar to standard PPO (0.1-0.2) but on sequence-level ratios
