# Magic Rectangle Rigidity (2×3 exact value, arXiv:2610.12001)

Exact quantum value + full rigidity classification for the 2×3 magic rectangle nonlocal game; connections to randomness expansion thresholds and parity-oblivious random access codes.

## Core Method

**Game**: Alice gets row x∈{0,1}, outputs 3 signs with product +1; Bob gets column j∈{1,2,3}, outputs 2 signs with product −1. Win iff intersection signs agree. Classical value 5/6.

**Theorem 2.1 — exact value**:
```
ω_Q(2,3) = ω_co(2,3) = (1 + √(2/3))/2
```
holds for tensor-product AND commuting-operator strategies (exact at level 1+AB of NPA hierarchy = almost-quantum relaxation).

**Exact sum-of-squares certificate (Theorem 3.1)**: after local projective dilation to Hermitian reflections (D_j² = C_j² = B_j² = I, D₁D₂D₃ = I, C₁C₂C₃ = −I, r = √(8/3), q = 2/r):
```
2rI − S = Σ_j (5r/64)(Z_j − qI)² + (r/12)(Y_j − V_j/r)² + (1/192)(X_j + qB_j − qW_j)²
```
with X_j = D_j + C_j, Y_j = D_j − C_j, Z_j = X_j B_j, V_j = X_iB_k + X_kB_i, W_j = Y_iB_k + Y_kB_i. Every coefficient positive → S ≤ 2√6 I in every commuting-operator representation.

**Rigidity (equality analysis)**: vanishing SoS residuals fix the measurement algebra:
- Reference strategy via **conference matrix**: M Mᵀ = 3I, zero diagonal, ±1 off-diagonal; U₀ = M/√3.
- Row observables D_j⁰ = diag(±1) on ℂ⁴; C_j⁰ = −U₀ D_j⁰ U₀*; anticommutation {D_j⁰, C_j⁰} = 2I, (X_j⁰)² = (3/8)·3I/... reflections for Bob: B_j⁰ = (X_j⁰)ᵀ/q.
- **Every optimal finite-dimensional strategy**: ∃ local isometries with ψ_ABE ↦ |Φ₄⟩ ⊗ |η⟩ (maximally entangled pair of 4-dim systems + ancilla); on support images, Alice's effects = P_a⁰⊗I / Q_a⁰⊗I, Bob's observable = B_j⁰⊗I. Local support dimension divisible by 4; dimension 4 necessary+sufficient.
- Correlation identity on |Φ₄⟩: ⟨A⊗B⟩ = Tr(ABᵀ)/4 → each intersection correlation 2/3.

**Self-testing pipeline (reusable pattern)**:
1. Express game score as Bell-operator expectation.
2. Exact SoS decomposition of (bound − operator) with positive coefficients.
3. Equality conditions → operator relations (anticommutation, algebra generated by two 4-outcome measurements).
4. Construct local isometries extracting |Φ₄⟩; keep Eve in ancillary factor (preserve purification coherence).

**Perfect-prediction threshold (magic-square link)**: largest score compatible with Eve perfectly predicting Alice's first row = β₀ = (2+√(2/3))/3. Above threshold, replacement argument: 1 − G(β₀+δ) = Θ(δ) linear in excess; same order for conditional min-entropy and von Neumann entropy. Mixture construction (threshold branch weight 1−t, perfect branch t): w_t = (1−t)β₀ + t, guessing 1 − 3t/4. Transfers via [5, Lemma 6.6] to Parity-MSG games N≥2 parties.

**Classification at threshold (Theorem 5.3)**: Eve's perfect guessing POVM forces orthogonal subspaces E_k = supp τ_k per key value; key POVM deterministic on Alice supports H_A,k; strategy = |Φ₄⟩-extraction per branch with coherence ψ = Σ√p_k ψ_k preserved. **No measurement performed** — vector identity decomposition.

**RAC equivalence (Theorem 7.x)**: two row measurements = remote preparations of two ensembles; 8 encoding states ρ_s (s∈{±1}³) with parity-oblivious constraint (27): Σ_{s_j=+1} ρ_s/4 = Σ_{s_j=−1} ρ_s/4. Solves 3-bit case of Chailloux–Kerenidis–Kundu–Sikora open problem: decoding optimum = 1/2 + 1/√6 ≈ 0.908248 for arbitrary finite encoding dimension (corrects Roy–Pan preprint value 0.902369). Rigidity transfers: ∃ isometry V with Vρ_{±α_a}V* = P_a⁰/Q_a⁰ ⊗ σ (single input-independent ancillary state); decoders on support = (I₄ + bB_j⁰)/2 ⊗ I.

**Approximate parity hiding (Prop 7.3)**: trace distance e = ‖τ₊ − τ₋‖₁ between parity averages; corrected states exist with score p̃ = p/(1+e) + e/(2(1+e)); if p > ω_Q(2,3) then e ≥ √6(p − ω_Q). Dimension-independent.

## Key Lessons

- **SoS certificate + equality relations = rigidity**: the same algebraic identity proves optimality AND classifies strategies — design residuals so their zeros encode the reference measurements.
- **Conference matrices** (zero diagonal, MMᵀ = (n−1)I) build the two orthonormal bases for parity-constrained row answers.
- **Almost-quantum tightness**: computing the value at NPA level 1+AB exactly often settles the unrestricted tensor-product value — check this level first.
- **Game↔code duals**: nonlocal game optimum ↔ prepare-and-measure RAC optimum via remote preparation + purification; privacy constraints transfer across the duality.
- **Threshold + linear guessing order** is the standard shape for randomness-expansion arguments: score excess δ ↦ entropic quantities Θ(δ).

## Verification Hooks

- Numerical: ω_Q = (1+√(2/3))/2 ≈ 0.908248 vs classical 5/6 ≈ 0.8333.
- Check M Mᵀ = 3I for the 4×4 conference matrix M (zero diagonal, ±1 elsewhere, rows = even sign strings).
- Verify Σ intersection correlations = 2/3 each on |Φ₄⟩ with reference observables.
