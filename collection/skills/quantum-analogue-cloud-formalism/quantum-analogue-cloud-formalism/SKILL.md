# A Quantum-Analogue Formalism for Modeling Supraliminal Information Processing

## Summary
Cloud-function formalism describing sensory-information processing in large-scale brain networks and mental representation. Governing equation based on neural-field model with polynomial nonlinearities and global phase-shift invariance. Interpreted as Schrodinger-type equation with nonlinear non-Hermitian Hamiltonian plus Lotka-Volterra terms.
