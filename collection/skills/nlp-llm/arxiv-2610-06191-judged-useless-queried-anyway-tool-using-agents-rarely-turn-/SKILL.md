# Judged Useless, Queried Anyway: Tool-Using Agents Rarely Turn Their Own Evidence Judgments into Stopping Decisions

**arXiv:** [2610.06191](https://arxiv.org/abs/2610.06191)
**Authors:** Chubin Zhang et al.
**Categories:** cs.AI; cs.CL
**Utility Score:** 0.86

## Abstract

We study a surprising disconnect in tool-using LLM agents: agents frequently judge retrieved evidence as useless for the current query yet continue to issue further tool calls anyway. Across multiple agent architectures and benchmarks, we find that agents rarely turn their own evidence-quality judgments into stopping decisions, suggesting a fundamental misalignment between internal evaluation and external action selection.
