## Overview

## Core Innovation

Extends fMRI cognitive taskonomy from **single-source** to **multi-source** transfer learning:
- Traditional: one-to-one transfer (single source → target)
- This work: multi-source transfer quantifying task relations across multiple source tasks simultaneously

## Key Methodology

1. **Masked fMRI Reconstruction** as self-supervised objective
2. **Transfer Relation Quantification** among cognitive task states
3. **Multi-Source Taskonomy** capturing shared and specialized neural processes

## Technical Framework

- Self-supervised learning via masked reconstruction
- Transfer learning analysis across fMRI task states
- Quantification of task similarity/dissimilarity

## Applications

- Cognitive task taxonomy construction
- Neural representation analysis
- Brain encoding model comparison
- Cross-task transfer prediction

## Key Concepts

- **Taskonomy**: Task relationship taxonomy based on neural representations
- **Transfer Learning**: Knowledge transfer between cognitive tasks
