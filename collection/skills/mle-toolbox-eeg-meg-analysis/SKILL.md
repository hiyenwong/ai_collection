# MLE-Toolbox: Comprehensive EEG and MEG Data Analysis

## Summary
Open-source MATLAB toolbox for end-to-end MEG/EEG analysis with unified GUI. Integrates preprocessing, source localization, functional connectivity, oscillatory analysis, and ML classification in one platform.

## Core Features

### Preprocessing
- Raw data import (MEG/EEG)
- Automated artifact rejection: ICA, SSP, SSS
- Signal-space projection and separation

### Source Localization
- Minimum Norm Estimation (MNE)
- Dynamic Statistical Parametric Mapping (dSPM)
- sLORETA
- Beamforming

### Analysis Capabilities
- Multi-atlas parcellation with anatomical visualization
- Spectral power analysis with frequency-band brain mapping
- Phase-amplitude coupling (PAC)
- Graph-theoretic brain network analysis
- Oscillatory analysis

### Machine Learning
- Integrated ML classifiers
- Deep learning classifiers
- One-click academic report generation

### Interoperability
- Native compatibility with Brainstorm, FieldTrip, EEGLAB, FreeSurfer
- Builds on established workflows with additional automation
- Interactive visualization

## Applications
- Clinical MEG/EEG research
- Source localization studies
- Brain connectivity analysis
- Neuromarker discovery
- Reproducible neuroimaging research
