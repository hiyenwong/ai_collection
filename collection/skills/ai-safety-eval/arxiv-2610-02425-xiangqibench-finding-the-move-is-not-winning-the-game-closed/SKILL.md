# XiangqiBench: Finding the Move Is Not Winning the Game - Closed-Loop Evaluation of LLM Agents

**arXiv:** [2610.02425](https://arxiv.org/abs/2610.02425)
**Authors:** Yekun Chai, Qiwei Peng, Haoyi Xiong
**Categories:** cs.AI; cs.MA
**Utility Score:** 0.86

## Abstract

Static evaluations credit a language model for naming the right move, but an agent must carry a plan through to a verified outcome while an opponent responds. We introduce XiangqiBench, an executable benchmark that measures this difference in Chinese chess: starting from 119 tactical endgames with forced mates, an LLM agent must deliver checkmate against an engine defender. We record 8,568 multi-turn trajectories from 12 frontier LLMs.
