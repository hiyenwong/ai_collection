# The Crowd in the Machine: A Crisis-Informatics Reading of the 2026 Autonomous Agent Incidents

**arXiv ID:** 2609.31060
**Categories:** cs.MA, cs.SI
**Utility Score:** 0.85

## Summary

This paper applies crisis-informatics methodology to analyze autonomous agent incidents from 2026, examining the sociotechnical dimensions of agent failures and coordination breakdowns. The work provides a systematic reading of real-world agent incidents through the lens of crisis informatics.

## Key Contributions

1. **Crisis-Informatics Approach**: Applies crisis-informatics methodology to autonomous agent incidents
2. **2026 Incident Analysis**: Systematic analysis of real-world autonomous agent incidents from 2026
3. **Sociotechnical Perspective**: Examines both technical and social dimensions of agent failures
4. **Coordination Breakdowns**: Identifies patterns in multi-agent coordination failures

## Relevance to AI Systems

- **Incident Analysis**: Provides framework for analyzing real-world agent incidents
- **Crisis Response**: Informs crisis response strategies for autonomous agent failures
- **Sociotechnical Understanding**: Bridges technical agent behavior with social impact considerations
