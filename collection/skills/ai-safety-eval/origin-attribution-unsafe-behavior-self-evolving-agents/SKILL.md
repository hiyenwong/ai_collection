# Origin Attribution for Unsafe Behavior in Self-Evolving Multi-Agent Coding Systems

**arXiv ID:** 2610.17488  
**URL:** https://arxiv.org/abs/2610.17488  
**PDF:** https://arxiv.org/pdf/2610.17488

## Abstract

As language-model-based coding agents evolve their programs and reuse code from one another, safety failures can acquire a history that extends beyond any single agent. We study the problem of origin attribution: determining which agent in a self-evolving multi-agent system introduced unsafe behavior. We propose an attribution framework that traces unsafe code patterns back to their source agents, even as code is modified, merged, and reused across the system. Experiments show that our framework accurately identifies origin agents in complex evolution scenarios.
