# Working Memory in Recurrent SNNs with Heterogeneous Synaptic Delays

> Biologically-inspired working memory implementation using recurrent spiking neural networks with diverse synaptic delay timescales.

## Metadata
- **Source**: arXiv:2604.14096v1
- **Published**: 2026-04-15
- **Categories**: q-bio.NC

## Core Methodology

### Key Innovation
Working memory in biological neural circuits relies on diverse synaptic delay timescales. This methodology implements working memory in recurrent SNNs using heterogeneous delays, mimicking biological neural mechanisms for information retention and processing.

### Technical Framework
1. **Heterogeneous Delay Architecture**: Implement synaptic connections with variable delay distributions
2. **Recurrent Connectivity**: Create feedback loops for sustained neural activity
3. **Memory Encoding**: Store information through activity patterns across delay timescales

## Implementation Guide

### Step-by-Step
1. **Design recurrent SNN topology** with multiple delay timescales
2. **Configure synaptic delays** according to biological distributions
3. **Train or tune network** for specific working memory tasks
4. **Evaluate memory capacity** and retention duration

### Applications
- Biologically-plausible memory models
- Delay-based reservoir computing
- Sequential information processing
- Cognitive modeling

## Pitfalls
- Delay timescale selection requires careful tuning
- Stability depends on delay distribution
- May require larger networks for complex memory tasks
