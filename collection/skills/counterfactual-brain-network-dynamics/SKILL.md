# Counterfactual Analysis of Brain Network Dynamics

## Overview

Causal inference in brain networks has traditionally relied on regression-based models such as Granger causality and dynamic causal modeling. While effective for identifying directed associations, these methods remain descriptive. We introduce a counterfactual framework for brain network dynamics that combines structural causal models with neural mass equations, enabling simulation of network responses to hypothetical interventions.
