# Multimodal Higher-Order Brain Networks: A Topological Signal Processing Perspective

## Overview

Brain connectomics is still largely dominated by pairwise-based models, such as graphs, which cannot represent circulatory or higher-order functional interactions. We propose a multimodal framework based on Topological Signal Processing (TSP) that models the brain as a higher-order topological domain using simplicial complexes that capture multi-region interactions.
