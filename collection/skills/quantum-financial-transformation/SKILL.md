# Quantum Computing for Financial Transformation

Framework for evaluating quantum computing applications in finance across five connected domains.

## Five-Domain Framework

### 1. Constrained Portfolio Optimization

- **Bottleneck**: Combinatorial search with hard constraints (budget, cardinality, sector limits)
- **Quantum Primitive**: QAOA, Quantum Annealing, VQE
- **Classical Benchmark**: Mixed-integer programming, heuristic methods
- **Assessment**: Strongest near-term case when constrained search dominates
- **Key insight**: Hybrid classical-quantum workflows outperform pure approaches

### 2. Derivative Pricing

- **Bottleneck**: High-dimensional Monte Carlo integration for path-dependent options
- **Quantum Primitive**: Quantum Amplitude Estimation (QAE)
- **Classical Benchmark**: Monte Carlo, quasi-Monte Carlo
- **Assessment**: QAE provides quadratic speedup for repeated expectation evaluation
- **Key insight**: Advantage materializes for complex, multi-dimensional pricing

### 3. Tail-Risk and Scenario Estimation

- **Bottleneck**: Estimating extreme event probabilities requires massive sampling
- **Quantum Primitive**: Amplitude estimation, quantum simulation
- **Classical Benchmark**: Historical simulation, stressed VaR
- **Assessment**: Quantum advantage for rare event probability estimation
- **Key insight**: Quadratic speedup meaningful for regulatory capital calculations

### 4. Quantum Machine Learning

- **Bottleneck**: High-dimensional feature spaces in financial prediction
- **Quantum Primitive**: Quantum kernels, variational circuits, QNN
- **Classical Benchmark**: Deep learning, gradient boosting, transformers
- **Assessment**: Task-dependent, strong evidence for specific structured problems
- **Key insight**: Quantum advantage not universal; depends on data structure

### 5. Post-Quantum Security

- **Bottleneck**: Current cryptographic infrastructure vulnerable to quantum attacks
- **Quantum Primitive**: Lattice-based, code-based, hash-based cryptography
- **Classical Benchmark**: RSA, ECC (vulnerable)
- **Assessment**: Already strategically necessary for long-term security
- **Key insight**: Migration planning required now, regardless of quantum timeline

## Evaluative Logic

For each domain, apply this evaluation framework:

1. **Identify the financial bottleneck**: What computational problem limits current capabilities?
2. **Specify the quantum primitive**: Which quantum algorithm addresses this bottleneck?
3. **Compare with classical benchmark**: What is the best classical alternative?
4. **Assess under realistic constraints**: How does it perform with NISQ-era hardware limitations?

## Main Conclusions

1. Hybrid workflows are the strongest near-term approach
2. No blanket claims of universal quantum advantage
3. Quantum optimization most credible when constrained search dominates
4. Amplitude estimation methods matter for repeated expectation evaluation
5. Quantum ML remains highly task-dependent
6. Post-quantum cryptography is already strategically necessary
