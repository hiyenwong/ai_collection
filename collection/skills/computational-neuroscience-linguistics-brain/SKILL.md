# Linguistics and Human Brain: Computational Neuroscience Perspective

## Overview
Interdisciplinary review bridging linguistic theory and neuroscience through computational models. Formalizes the hierarchical and dynamic structures of language into testable neural models, enabling computational dialogue between linguistic hypotheses and neural mechanisms.

## Key Themes

### 1. Language-Brain Relationship
- Hierarchical structure processing in cortex (syntax trees mapped to neural circuits)
- Dynamic neural representations of phonology, morphology, syntax, semantics
- Brain regions: Broca's area, Wernicke's area, angular gyrus, temporal lobe

### 2. Computational Neuroscience Methods for Language
- Neural network models of language processing
- fMRI/EEG/MEG analysis of linguistic stimuli
- Computational models of syntactic parsing and semantic composition

### 3. LLMs as Brain Models
- Comparing LLM internal representations with neural recordings
- Transformer attention patterns vs cortical processing
- Scaling laws and brain-like generalization

### 4. Bridging Theory and Neural Data
- Minimalist Program mapped to neural circuit models
- Dependency parsing in neural populations
- Information-theoretic approaches to language in the brain

## Applications
- Brain-computer interfaces for language restoration
- Understanding language disorders (aphasia, dyslexia)
- Multilingual brain representation studies
- LLM interpretability via neuroscience parallels

## Authors
Fudong Zhang, Bo Chai, Yujie Wu, Wai Ting Siok, Nizhuan Wang
