# The Funessian process: Non-Markovian dynamics shaped by the first event

- **arXiv**: 2605.28892
- **Date**: 2026-05-29
- **Topic**: Number Theory, Statistics, Advanced Mathematics + Quantum

## Abstract

Funessian过程：一种连续时间正可分非马尔可夫过程，具有初始状态记忆。平稳态下关联函数指数衰减（通常被视为马尔可夫特征），但记忆贯穿演化。互信息作为非马尔可夫性度量。应用于随机游走，展示记忆效应打破遍历性并改变扩散系数。

## Core Methodology

连续时间正可分非马尔可夫过程构造：满足微分Chapman-Kolmogorov方程

初始状态记忆：平稳态下关联函数指数衰减但记忆保持

互信息作为非马尔可夫性度量：可靠表征过程的非马尔可夫特征

随机游走应用：记忆效应打破遍历性，修正扩散系数等输运性质
