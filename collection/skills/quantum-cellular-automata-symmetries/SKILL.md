# Quantum Cellular Automata and Fusion Category Symmetries

## Core Methodology

### QCA-Refined Symmetry Realization

Analyze (1+1)d fusion category symmetries on tensor-product Hilbert spaces:

1. Check if fusion category is weakly integral (necessary condition for realizability)
2. Under physical assumptions on defects, QCA and symmetry-operator indices are determined by categorical data
3. Freedom exists in redefining symmetry operators
4. Construct lattice model for any weakly integral fusion category

### Index Theorem for QCA-Symmetry Systems

The QCA index and symmetry operator index are fixed by the categorical data of the fusion category, up to symmetry operator redefinition.

### Lattice Model Construction

For any weakly integral fusion category:
1. Define local Hilbert space per site
2. Construct symmetry operators from fusion category data
3. Build QCA that refines the symmetry realization
4. Verify indices match categorical predictions

## Reusable Patterns

### Pattern 1: Weakly Integral Check

A fusion category must be weakly integral (all Frobenius-Perron dimensions are square roots of integers) to be realizable on tensor-product Hilbert space.

### Pattern 2: Tambara-Yamagami Construction

For TY categories (generated by invertible objects + one non-invertible):
- Explicit lattice construction exists
- QCA index computable from categorical data
- Provides concrete realization of abstract symmetry

### Pattern 3: Defect Analysis

Physical assumptions on defects constrain QCA-refined realizations. Use defect analysis to derive index constraints.

## Mathematical Framework

### Fusion Category Data

- Simple objects and their fusion rules
- Frobenius-Perron dimensions
- Associators (F-symbols)
- Braidings (if braided)

### QCA Index

The GNV index measures the net flow of quantum information. For QCA-refined symmetries, the index is constrained by categorical data.

## Common Pitfalls

- Non-weakly-integral categories cannot be realized on tensor-product Hilbert spaces
- Index computation requires careful treatment of defect assumptions
- Symmetry operator redefinitions can change apparent indices
