# SKILL.md - Cognitive Dark Matter AI Evaluation

## Activation Keywords

- cognitive dark matter, CDM, AI evaluation
- jagged intelligence, metacognition, cognitive flexibility
- episodic memory, lifelong learning, abductive reasoning
- AI cognitive assessment, behavioral inference

## What It Does

Identifies and measures "Cognitive Dark Matter" (CDM) — brain functions that meaningfully shape behavior yet are hard to infer from behavior alone. Provides framework for AI cognitive evaluation beyond behavioral outcomes.

## When To Use

**Use this skill when:**
- Evaluating AI cognitive capabilities (not just performance)
- Identifying gaps in AI intelligence landscape
- Training AI on cognitive process vs behavioral outcome
- Assessing metacognition, flexibility, reasoning in AI
- Designing cognitive benchmarks for AI

**Do NOT use for:**
- Standard AI performance benchmarks (use existing tools)
- Behavioral-only evaluation (CDM focuses on process)
- Model architecture design (this is evaluation framework)

## How To Use

### Step-by-Step Workflow

1. **Identify CDM Domains**
   - Metacognition: self-awareness of knowledge/capabilities
   - Cognitive flexibility: adaptation to new contexts
   - Episodic memory: contextual event recall
   - Lifelong learning: continuous knowledge integration
   - Abductive reasoning: inference to best explanation
   - Social reasoning: understanding others' mental states
   - Common-sense reasoning: implicit world knowledge

2. **Design Complementary Data Types**
   - **Process data:** cognitive trajectory during task
   - **Introspection data:** self-reported reasoning/confidence
   - **Transfer data:** performance across related domains

3. **Measure CDM Signals**
   - Collect data beyond behavioral outcomes
   - Analyze cognitive process trajectories
   - Measure introspection accuracy
   - Test transfer/flexibility across contexts

4. **Train on Cognitive Process**
   - Use CDM signals as training objectives
   - Optimize for process quality, not just outcome
   - Reward cognitive flexibility and metacognition

5. **Evaluate Jaggedness**
   - Map performance across CDM domains
   - Identify "dark matter" gaps (low CDM, high behavior)
   - Target training on missing cognitive functions

### CDM Domain Assessment Matrix

| Domain | Behavioral Proxy | Direct CDM Measure |
|--------|------------------|-------------------|
| Metacognition | Confidence accuracy | Self-awareness tasks |
| Flexibility | Transfer performance | Context adaptation |
| Episodic memory | Recall accuracy | Contextual binding |
| Lifelong learning | Knowledge accumulation | Integration rate |
| Abduction | Explanation quality | Inference process |
| Social | Interaction success | Mental state attribution |
| Common-sense | Correctness | Implicit knowledge |

## Example Usage

### AI System CDM Assessment

**Input:**
```
AI model with good task performance but inconsistent reasoning
Question: "Why does the model fail on transfer tasks?"
```

**CDM Analysis:**
1. Assess metacognition → low confidence calibration
2. Test cognitive flexibility → poor context adaptation
3. Measure episodic memory → weak contextual recall
4. Identify CDM gap → cognitive flexibility

**Output:**
```
CDM Assessment Report:
- Metacognition: 0.45 (low)
- Flexibility: 0.32 (critical gap)
- Episodic memory: 0.60 (moderate)
- Lifelong learning: 0.55 (moderate)
- Abduction: 0.50 (moderate)

Recommendation: Add process data for flexibility training
```

### CDM Training Pipeline

**Design complementary data:**
1. **Process data:** Record reasoning trajectory during inference
2. **Introspection data:** Ask model to explain reasoning + confidence
3. **Transfer data:** Test across multiple related contexts

**Training objective:**
```
Loss = α * behavioral_loss + β * CDM_process_loss + γ * introspection_loss
```
