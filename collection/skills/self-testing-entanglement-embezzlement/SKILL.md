# Self-Testing of Exact Entanglement Embezzlement

## Description

Proves that any exact entanglement embezzlement protocol must arise from a unique state on the tensor product of the Cuntz algebra with itself. Uses modular theory to characterize the resulting von Neumann algebra as the unique separable approximately finite-dimensional Type III_lambda factor. Based on Harris (arXiv:2605.22713).

## Core Methodology

### 1. Entanglement Embezzlement Problem

Given a catalyst state vector |psi> in Hilbert space H, using unitaries U and V, a protocol transforms:

(U ⊗ I_d)(I_d ⊗ V)(e_0 ⊗ |psi> ⊗ e_0) = Σ_{i=0}^{d-1} α_i e_i ⊗ |psi> ⊗ e_i

where each α_i > 0 and Σ α_i² = 1.

### 2. Self-Testing Result

**Key theorem:** Any such protocol must arise from a unique state on the tensor product O_d ⊗ O_d of the Cuntz algebra with itself.

This proves exact entanglement embezzlement is a **self-test** for:
- A collection of d Cuntz isometries for each party
- A unique quasi-free state on the Cuntz algebra O_d

### 3. Modular Theory Characterization

The von Neumann algebra generated by the copy of O_d is the unique separable approximately finite-dimensional **Type III_λ factor** for some 0 < λ ≤ 1, where λ can be determined by an algebraic condition on the Schmidt coefficients of the state φ = Σ α_i e_i ⊗ e_i.

### 4. Mathematical Framework

| Component | Description |
|-----------|-------------|
| Cuntz algebra O_d | C*-algebra generated by d isometries with orthogonal ranges |
| Quasi-free state | State characterized by its 2-point functions |
| Type III_λ factor | von Neumann algebra classification by Connes |
| Modular theory | Tomita-Takesaki theory for von Neumann algebras |

## Error Handling

### Schmidt Coefficient Condition
The parameter λ of the Type III factor is determined by the algebraic properties of the Schmidt coefficients. Ensure the coefficients satisfy the normalization condition Σ α_i² = 1.

### Cuntz Algebra Constraints
The d isometries must satisfy s_i* s_j = δ_{ij} I and Σ s_i s_i* = I. Verify these relations hold in the protocol implementation.
