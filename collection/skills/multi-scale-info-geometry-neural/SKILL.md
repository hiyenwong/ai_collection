# Multi-Scale Information Geometry for Neural Population Analysis

## Overview

A novel framework using multi-scale information geometry to reveal the structure of mutual information in neural populations. This methodology defines a unique Riemannian representational geometry on stimulus space derived from first principles, where distances reflect how reliably stimuli can be distinguished from neural activity.

**arXiv ID**: 2605.06304v1
**Published**: 2026-05-07
**Authors**: Simone Azeglio, Steeve Laquitaine, Ulisse Ferrari, Matthew Chalk
**Categories**: q-bio.NC

## Core Problem

Understanding how neural population responses represent sensory information is central to systems neuroscience. While representational geometry approaches define distances on stimulus space based on stimulus discriminability, different constructions lead to qualitatively different conclusions about the neural code.

## Key Contributions

1. **Unique Riemannian Geometry**: Demonstrates that a unique Riemannian representational geometry emerges from first principles
2. **Multi-Scale Analysis**: Framework operates across multiple scales of neural population analysis
3. **Mutual Information Structure**: Reveals the structure of mutual information in neural populations
4. **First Principles Derivation**: Geometry is derived from fundamental information-theoretic principles

## Technical Details

### Information Geometry Foundation

- Uses Riemannian manifold structure on stimulus space
- Metric tensor derived from neural population response statistics
- Distances correspond to stimulus discriminability

### Multi-Scale Framework

- Analysis at population level (large-scale patterns)
- Intermediate scales (subpopulation dynamics)
- Fine-scale (individual neuron contributions)

### Mutual Information Analysis

- Characterizes how information is distributed across neural populations
- Reveals redundancy and synergy in population codes
- Connects geometric structure to information processing capacity
