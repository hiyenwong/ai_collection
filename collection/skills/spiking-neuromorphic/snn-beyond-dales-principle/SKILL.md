# Collective Dynamics in SNNs Beyond Dale's Principle

> Investigation of collective dynamics in spiking neural networks where neurons can be both excitatory and inhibitory, violating Dale's principle.

## Metadata
- **Source**: arXiv:2602.23202v1
- **Published**: 2026-02-26
- **Categories**: q-bio.NC, cond-mat.dis-nn

## Core Methodology

### Key Innovation
Dale's principle states that neurons release the same neurotransmitter at all synapses. This research explores collective dynamics when this principle is violated, enabling neurons with mixed excitatory and inhibitory outputs.

### Technical Framework
1. **Mixed Neuron Models**: Neurons can produce both E and I outputs
2. **Dynamic Balance**: Self-tuning excitation-inhibition balance
3. **Collective Phenomena**: Emergent dynamics in mixed-type networks
4. **Criticality Analysis**: Study phase transitions in mixed networks
