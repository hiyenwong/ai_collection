# KG Database Schema (Verified 2026-05-26)

**Database path**: `/Users/hiyenwong/.openclaw/workspace/scripts/kg.db`

## Tables

### entities
| Column | Type | Description |
|--------|------|-------------|
| id | TEXT PRIMARY KEY | arxiv ID (e.g. '2605.00026v1') or 'author:Name' |
| name | TEXT | paper title or author name |
| type | TEXT | 'paper', 'author', 'skill', 'keyword' |
| category | TEXT | arxiv category ('quant-ph', 'q-bio.NC') |
| description | TEXT | abstract or description |
| source | TEXT | arxiv abs URL or empty |
| created_date | TEXT | YYYY-MM-DD |

### relationships
| Column | Type | Description |
|--------|------|-------------|
| id | TEXT PRIMARY KEY | composite key like '2605.00026_by_Author_Name' |
| source | TEXT | entity id (paper) |
| target | TEXT | entity id (author/keyword) |
| relation | TEXT | 'authored_by', 'HAS_KEYWORD', 'CITES', 'related_topic' |
| description | TEXT | relation description |
| created_date | TEXT | YYYY-MM-DD |

### kg_vectors
| Column | Type | Description |
|--------|------|-------------|
| id | TEXT PRIMARY KEY | matches entities.id |
| embedding | TEXT | JSON array of floats (128-dim) |

### research_log
| Column | Type | Description |
|--------|------|-------------|
| id | TEXT PRIMARY KEY | unique log entry id |
| date | TEXT | YYYY-MM-DD |
| topic | TEXT | research topic |
| arxiv_id | TEXT | paper arxiv id |
| skill_name | TEXT | associated skill |
| summary | TEXT | research summary |
| status | TEXT | import status |

## Key Changes from Old Schema

| Old | New |
|-----|-----|
| `kg_entities` table | `entities` table |
| `kg_relations` table | `relationships` table |
| INTEGER auto-increment id | TEXT arxiv id |
| `title` column | `name` column |
| `content` column | `description` column |
| `url` column | `source` column |
| `authors` column | separate author entities |
| `published_date` column | `created_date` column |
| `kg_vectors.entity_id` INTEGER | `kg_vectors.id` TEXT |
| `kg_vectors.vector` BLOB | `kg_vectors.embedding` TEXT (JSON) |
| `relationships.type` | `relationships.relation` |
