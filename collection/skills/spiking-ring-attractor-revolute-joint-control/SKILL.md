# Spiking Ring-Attractor Architecture for Representation and Control of Revolute Robot Joints

**Source**: A. Htet, A. Rodriguez Jimenez, R. Ma, A. Di Nuovo (Sheffield Hallam Univ.), arXiv:2610.26027 (cs.RO/cs.NE, Oct 2026). Validated in NEST (iaf_psc_alpha) + on a Tiago arm via ROS.

## When to use

- A spiking/neuromorphic controller must represent and regulate a state that lives on a CIRCLE (revolute joint angle, heading, phase) — i.e., the state topology is S^1, not R.
- You want representation and control unified in one neural substrate: no decode-to-scalar -> PID -> encode round trip; the population bump itself is the controlled state.
- Multi-joint revolute chains need an end-effector orientation readout composed from distributed ring activity.

## Core architecture (single joint)

Four modules closing one loop:
1. **Goal ring** — desired joint phase as a localized bump. 2. **State ring** (200 neurons, iaf_psc_alpha) — current joint phase as a bump. 3. **Positional Fourier readout** — decodes each bump to a scalar phase estimate. 4. **Hammel-style homeostatic comparator** — signed mismatch theta_g - theta_s drives **opponent left-gain (LG) / right-gain (RG) populations** that transport the state bump toward the goal; when mismatch -> 0 the opponent signals balance and the bump stops.

## Mechanism chain

**1. Ring attractor as SO(2) orbit.** Connectivity is rotation-invariant; stable states are translated bumps u_r(theta,t) ~ f(theta - phi(t)). Controlled coordinate = bump centroid phi in S^1. The bump family is an orbit of the rotation group; tangent direction generated by J = -d/dtheta. Any input that must MOVE the represented angle has to project on J u, not merely perturb firing rates.

**2. Opponent gain modulation = Lie-algebraic transport.** Gain populations receive phase-SHIFTED copies of ring activity plus scalar homeostatic drives (eq 3):
   u_g+(theta) = W_rg g(u_r(theta + dtheta)) + B+(t);  u_g-(theta) = W_rg g(u_r(theta - dtheta)) + B-(t).
First-order expansion in dtheta splits the summed feedback into a symmetric part (no direction) and a directional part ~ (W_rg dtheta) g'(u_r)[g'(x+) - g'(x-)] * d/dtheta u_r. Collected ring dynamics become a transport equation (eq 5-7):
   d/dt u_r + c(u_r) d/dtheta u_r = F_r(u_r)  <=>  d/dt u_r = F_r(u_r) + c(u_r) J u_r,
   c(u_r) = (W_gr W_rg dtheta / tau_r) g'(u_r) [g'(x+) - g'(x-)].
KEY: balanced drive B+ = B- gives x+ = x- => g'(x+) - g'(x-) = 0 => NO transport (symmetry preserved). Signed imbalance B+ - B- selects direction; magnitude sets speed.

**3. Phase reduction.** On the single-bump manifold, transport reduces to phidot(t) = c_eff(t): opponent gain modulation encodes VELOCITY along the ring, not angle. Integration of that velocity is what moves the internal joint state — a spiking integrator-by-transport.

**4. Analytic Fourier phase decoder** (Appendix C; numerically re-verified). The centroid estimator is a projection onto a centered ramp; on the periodic ring the ramp is a pure sine series: x - L/2 = -(L/pi) * sum_m sin(2*pi*m*x/L)/m. Hence the linear decoder
   theta_hat = b + sum_m w_m S_m(g), S_m(g) = sum_x g(x) sin(2*pi*m x/L), b = L/2, w_m = -L/(pi*M0*m),
M0 = bump mass. Shape correction: for a translated bump S_m(g) = A_m sin(2*pi*m*theta/L) with A_m the bump shape's cosine coefficient (EXACT for symmetric bumps; verified to 2e-13), so corrected weights w_m = -L/(pi*m*A_m) make the decode exact up to the O(1/K) sawtooth truncation tail (measured decode errors 0.078-0.100 at K=110, matching the Dirichlet tail bound 0.094-0.101). A SINGLE mode (K=1) already gives coarse phase; K=50 is accurate at population granularity.
**Signed spiking implementation** (Appendix D): sine features are +/-, spike counts are not — each feature is a PUSH-PULL pair S_m = S_m+ - S_m-, recovered by subtraction.

**5. Product-feature forward-kinematic readout** (Appendix E). Per ring i retain first harmonics C_i ~ cos q_i, S_i ~ sin q_i and the constant 1 -> local feature phi_i = [1, C_i, S_i]. A coordinate-axis rotation is LINEAR in (1, cos q, sin q) (eq 18), so for a serial chain R_ee = R_a1(q1)...R_an(qn), every matrix entry is a sum of products of local sines/cosines, all contained in the tensor product Phi(n) = phi_1 (x) ... (x) phi_n (3^n entries; 27 for 3 rings). Exact linear readout vec(R_ee) = T Phi(n) for coordinate-axis chains (fixed matrix T from the kinematic convention; ORDER MATTERS — rotations do not commute). SO(3) recovery: theta_hat = -arcsin(r31), lambda_hat = atan2(r32, r33), psi_hat = atan2(r21, r11), valid away from cos theta = 0. Push-pull pairs implement the signed product features; signed products project to output rings for lift/pitch/yaw — composition stays INSIDE the neural substrate. This is a READOUT, not a control law: orientation is the forward-kinematic image of independently controlled SO(2) ring trajectories.

## Results / evidence
- NEST: 200-neuron state ring + comparator + LG/RG transports the bump toward goal phases; residual error is target-dependent (nonuniform transport field from finite-size spiking, decoder resolution, gain calibration). Opponent channels show the predicted complementary push-pull engagement by mismatch sign.
- Tiago: signed velocity command s_t = R_t - L_t (right minus left gain spike counts, eq 12), exponential filter, separate calibration gains for the two signs -> receding-horizon joint trajectories via ROS. Directed motion on all 7 arm joints; accuracy is joint-dependent (range, mechanics, calibration), not a mechanism failure. Ring controller converges slower than PID but with smaller, smoother commands.
- FK decoder: two-ring NEST decoder R = Rx(q1) Ry(q2); decoded lift/pitch/yaw track analytic targets across config slices; discontinuities are circular wrap-around (sawtooth), not decoder failure; circular index error remains small.

## NEST parameters (Table 1)
V_th 0.8 mV (ring, homeostatic) / 1.35 (gain); tau_m 7.04 ms; C_m 3.96e6 pF; tau_syn_ex 27 ms (75 homeostatic); tau_syn_in 50 ms; I_e 4.5e5 pA (9.0e5 homeostatic, 0 gain); N=200 ring neurons, N_pos=30 represented positions, readout scale 200, ridge 1e-6; w_h->g = 1.0e4; w_r->g = 4.5e5; w_g->r = -0.6; w_cross = -3.0e4 (cross-inhibition).

## Pitfalls / lessons
- The controlled variable is the BUMP CENTROID, not individual rates — perturbations that break bump coherence are out of scope; once the bump stays coherent, single-neuron errors need not corrupt the phase (population robustness argument).
- Direction requires SYMMETRY BREAKING: balanced opponent drive never moves the bump. Do not add scalar drive and expect motion — only the imbalance B+ - B- projects on the tangent J u.
- Gain encodes velocity: set-point regulation is integration of c_eff, so the loop is an integrator-by-transport — expect slower, smoother convergence than a PID (confirmed empirically).
- Decoder truncation: the sawtooth tail is O(1/K); with finite-width bumps A_m decays like exp(-2 pi^2 m^2 w^2 / L^2) so high modes fall below spiking/rounding noise — K is capped by bump width, not by desire for accuracy. Single-mode readout is deliberately coarse.
- FK readout assumes KNOWN axes and fixed multiplication order; non-coordinate-axis joints or long chains need feature pruning / low-rank approximation (3^n growth).
- Ring attractor substrate extends naturally: offline replay/imagined trajectories (hippocampal-replay-style) and predictive rollouts over embodied state spaces are the suggested applications.
