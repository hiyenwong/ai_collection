# A Society of Researchers: Designing Institutions for Agent Populations

**arXiv:** [2610.10468](https://arxiv.org/abs/2610.10468)
**Utility:** 0.88

## Key Argument

Deployments of research agents are moving to **populations of thousands** sharing one pool of compute. Most current systems:
- Organize one project at a time, OR
- Leave the population unorganized

**Claim:** Such a population will acquire an organization whether or not designers provide one — so designers should provide it explicitly.

## Core Contribution

Institutional design framework for large-scale agent populations:
- Resource allocation mechanisms
- Coordination protocols
- Governance structures
- Multi-agent systems community tools applied to population-level organization

## Practical Use

- Design institutions for large agent deployments
- Manage shared compute resources across agent populations
- Prevent emergent dysfunctional organization in agent societies
