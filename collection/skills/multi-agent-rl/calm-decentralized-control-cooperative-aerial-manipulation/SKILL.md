# CALM: Decentralized Control of Cooperative Aerial Manipulation with Multi-Agent Reinforcement Learning

**arXiv ID:** 2610.18425  
**URL:** https://arxiv.org/abs/2610.18425  
**PDF:** https://arxiv.org/pdf/2610.18425

## Abstract

Cooperative aerial manipulation is difficult under wind, payload motion, and noisy goal broadcasts because multiple Unmanned Aerial Vehicles (UAVs) must agree on force distribution without centralized oversight. We present CALM, a decentralized multi-agent reinforcement learning framework for cooperative aerial manipulation. Each UAV learns a local policy that coordinates with peers through implicit communication via shared observations. CALM achieves robust cooperative manipulation under adverse conditions where centralized approaches fail.
