# DAEDALUS: Bootstrapping Agent Memory from Self-Generated Tasks

**arXiv:** [2610.08048](https://arxiv.org/abs/2610.08048)
**Authors:** Antoine Edy et al.
**Categories:** cs.AI; cs.CL; cs.LG
**Utility Score:** 0.88

## Abstract

We introduce DAEDALUS, a training-free method that builds environment-specific memory from self-generated tasks without curated tasks or an oracle verifier. DAEDALUS involves auxiliary agents that explore the environment to create solvable tasks and their success criteria, and a solver agent that attempts these tasks. The solver learns from its failures, as each one is turned into an in-context heuristic that guides its subsequent attempts.
