# AMBER: Training Long-Horizon Web Agents through Append-Only Memory

**arXiv:** [2610.07118](https://arxiv.org/abs/2610.07118)
**Authors:** Chinmay Savadikar et al.
**Categories:** cs.AI; cs.LG
**Utility Score:** 0.88

## Abstract

We introduce AMBER (Append-only Memory Bank for Evidence Retention) - a simple and scalable framework where an agent jointly learns to reason, act, and write free-form memory entries into an append-only bank. The memory bank accumulates evidence across long-horizon web interactions, enabling the agent to recall and reuse prior observations. AMBER achieves state-of-the-art results on long-horizon web agent benchmarks while maintaining interpretability through human-readable memory entries.
