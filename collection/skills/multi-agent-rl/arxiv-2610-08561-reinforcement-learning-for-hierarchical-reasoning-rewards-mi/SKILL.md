# Reinforcement Learning for Hierarchical Reasoning Rewards: Minimax-Optimal Rates with Transformers

**arXiv:** [2610.08561](https://arxiv.org/abs/2610.08561)
**Authors:** Naoki Nishikawa, Taiji Suzuki
**Categories:** cs.LG; stat.ML
**Utility Score:** 0.87

## Abstract

We address why on-policy exploration combined with a neural reward model is effective for RL post-training by modeling the reward as a hierarchical function on the response space. We show that a natural Transformer-based actor-critic algorithm achieves the minimax optimal rates in the query budget and in the regularization strength up to logarithmic factors. In contrast, we prove that sampling from the fixed reference distribution, as in offline reward modeling, can limit regret decay to a logarithmic rate.
