# Spatial Pattern Formation from Multi-Agent Learning in Public Goods Dilemmas

**arXiv:** [2610.12321](https://arxiv.org/abs/2610.12321)
**Utility:** 0.85

## Key Question

How do spatial patterns emerge when agents learn where to move, and how do learning rates shape consequences for collective welfare?

## Method

- Spatial public goods models with learned movement policies
- Tabular Q-learning with local observations
- Fixed populations of cooperators and defectors learning independently

## Findings

- Cooperator learning rates vs defector learning rates create different spatial patterns
- Learning rates significantly impact collective welfare outcomes
- Movement toward richer locations generates emergent spatial structure

## Practical Use

- Understand emergent behavior in spatial multi-agent systems
- Design learning rates that promote cooperation
- Analyze spatial dynamics in MARL deployments
