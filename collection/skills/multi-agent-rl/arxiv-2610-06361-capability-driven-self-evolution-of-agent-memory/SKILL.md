# Capability-Driven Self-Evolution of Agent Memory

**arXiv:** [2610.06361](https://arxiv.org/abs/2610.06361)
**Authors:** Yaoqi Chen et al.
**Categories:** cs.AI
**Utility Score:** 0.86

## Abstract

We study how agent memory systems can self-evolve based on capability gaps identified during task execution. Rather than accumulating all experiences uniformly, our approach selectively evolves memory structures to address specific capability deficiencies, leading to more efficient learning and better generalization across tasks.
