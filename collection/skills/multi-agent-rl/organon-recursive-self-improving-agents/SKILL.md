# Organon: From Evolutionary Search to Recursive Self-Improving Agents for Scientific Discovery

## Core Contribution

Organon introduces a recursively self-improving framework for automated scientific discovery that evolves not just solutions but the search methodologies themselves. Unlike fixed LLM-guided evolutionary search, Organon adapts research methods dynamically as investigations unfold.

## Key Insights

- **Problem**: Existing LLM-guided evolutionary frameworks use fixed search procedures or restrict adaptation to predefined components, limiting their ability to address diverse research problems
- **Solution**: Recursive self-improvement where the system evolves its own search strategies based on runtime challenges
- **Mechanism**: Methods vary across domains and evolve through experimentation, mirroring how human research methodologies develop

## Technical Approach

1. **Recursive Architecture**: The system improves its own improvement process
2. **Dynamic Method Adaptation**: Search procedures evolve based on problem characteristics encountered during execution
3. **LLM-Guided Evolution**: Combines large language models with evolutionary search for flexible methodology generation

## Applications

- Automated scientific discovery across diverse domains
- Adaptive optimization where problem characteristics change during search
- Meta-level evolutionary systems that improve their own search strategies
