# ARIA: Runtime Inspection and Amendment for Multi-Agent Systems

**arXiv:** [2610.20780](https://arxiv.org/abs/2610.20780)
**Utility Score:** 0.92
**Date Added:** 2026-10-16

## Abstract

In LLM-based multi-agent systems (MAS), a local mistake can propagate as other agents build on it, turning a correctable error into a failed task. ARIA learns when and how to repair ongoing multi-agent executions by turning execution traces into a learned intervention policy.

## Key Contributions

- Novel runtime inspection framework for multi-agent systems
- Learned policy for intervening during execution (not just post-hoc)
- High utility score (0.92) indicating significant research value
