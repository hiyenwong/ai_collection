# RelLedger: Relational Information Governance for LLM Agent Organizations

**arXiv ID:** 2610.16281  
**URL:** https://arxiv.org/abs/2610.16281  
**PDF:** https://arxiv.org/pdf/2610.16281

## Abstract

In LLM agent organizations, shared records determine which facts are available for later decisions. A sender consults interaction histories before deciding what to communicate; a receiver uses those records to evaluate credibility. We propose RelLedger, a relational information governance framework for LLM agent organizations. RelLedger maintains a structured ledger of inter-agent interactions that supports provenance tracking, credibility assessment, and conflict resolution. The framework enables agents to make better decisions by providing access to verified interaction histories and relational context.
