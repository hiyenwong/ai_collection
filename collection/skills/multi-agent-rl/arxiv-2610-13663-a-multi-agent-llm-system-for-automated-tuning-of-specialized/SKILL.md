# A Multi-Agent LLM System for Automated Tuning of Specialized Neural Network Models

**arXiv:** [2610.13663](https://arxiv.org/abs/2610.13663)
**Authors:** Ivan Moloshnikov et al.
**Categories:** cs.AI; cs.CL; cs.LG; cs.MA; cs.NE
**Utility Score:** 0.86

## Abstract

We present a multi-agent LLM system that automates the tuning of specialized neural network models. For a given task class the choice of key components is critical and usually manual. Our system uses multiple LLM agents to collaboratively explore the design space, replacing manual trial-and-error with automated, agent-driven optimization across architectures, hyperparameters, and training strategies.
