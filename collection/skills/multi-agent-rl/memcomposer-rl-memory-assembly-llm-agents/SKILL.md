# MemComposer: Learning to Assemble Memories for LLM Agents via Reinforcement Learning

**arXiv:** [2610.21091](https://arxiv.org/abs/2610.21091)
**Utility Score:** 0.90
**Date Added:** 2026-10-16

## Abstract

MemComposer jointly examines the current query and retrieved candidates to decide which experiences to include, how many to select, and how to order them, trained using reinforcement learning for optimal memory composition.

## Key Contributions

- RL-trained memory composer for LLM agents
- Joint optimization of selection, count, and ordering of memories
