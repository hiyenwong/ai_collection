# Scaling Generalist Data-Analytic Agents

## Abstract

Data-analytic agents are emerging as a key catalyst for automated scientific discovery. This paper introduces DataMind, a scalable data synthesis and agent training recipe designed to build generalist data-analytic agents. DataMind tackles three key challenges including insufficient data resources, improper training strategy, and unstable code-based multi-turn rollout. Built on DataMind, DataMind-14B achieves state-of-the-art with an average score of 71.16% on multiple data analysis benchmarks, outperforming the strongest proprietary baselines DeepSeek-V3.1 and GPT-5.
