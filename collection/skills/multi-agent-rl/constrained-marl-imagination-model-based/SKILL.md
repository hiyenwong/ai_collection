# Constrained Multi-Agent Reinforcement Learning in Imagination

**arXiv:** [2610.21319](https://arxiv.org/abs/2610.21319)
**Utility Score:** 0.88

## Abstract

Predicting cost in a multi-agent world model moves most constrained policy updates into imagination. CA-MAMBA achieves 2.8-12x reward improvement over model-free baselines at equal budget while halving cost violations.
