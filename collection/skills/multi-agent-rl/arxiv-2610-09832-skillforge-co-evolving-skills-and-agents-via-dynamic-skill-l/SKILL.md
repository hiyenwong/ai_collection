# SkillForge: Co-Evolving Skills and Agents via Dynamic Skill Lifecycles

**arXiv:** [2610.09832](https://arxiv.org/abs/2610.09832)
**Authors:** Yuyao Ge et al.
**Categories:** cs.AI
**Utility Score:** 0.91

## Abstract

We propose SkillForge, a framework where agents co-evolve with reusable skills through dynamic skill lifecycles. Skills are induced from successful trajectories, verified against evidence, deduplicated, and retired when obsolete. Accepted at NeurIPS 2026, SkillForge demonstrates that agents with evolving skill libraries substantially outperform static baselines across diverse agentic benchmarks, enabling continual improvement without retraining.
