# SkillNEO: Non-Elitist Evolutionary Optimization of Agent Skills

**arXiv:** [2610.20926](https://arxiv.org/abs/2610.20926)
**Utility Score:** 0.88
**Date Added:** 2026-10-16

## Abstract

Agent skills turn procedural knowledge into reusable artifacts. SkillNEO uses non-elitist evolution to allow new versions to receive edits even without immediate reward gains, preserving useful partial repairs before their benefits emerge.

## Key Contributions

- Non-elitist evolutionary optimization for agent skills
- Preserves partial improvements that don't show immediate gains
