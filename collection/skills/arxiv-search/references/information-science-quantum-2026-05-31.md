## Majorization Lattice Theory
- **arXiv:2605.30331** — "Majorization precursors to supermodularity and subadditivity on the majorization lattice" (Stévins, Jabbour, Deside, Cerf, cs.IT)
- Core: Two structural majorization relations ("precursors") underlie supermodularity and subadditivity
- All sum-concave functions (Tsallis, Rényi, Shannon entropies) inherit these properties simultaneously
- Strengthened: strict subadditivity for all entropies, strict supermodularity for Tsallis/Shannon
- Quantum info relevance: majorization is the core ordering relation in quantum state transformation theory

## Synthesis Pattern (Confirmed 2026-05-31)
When two same-day papers address complementary sides of a phenomenon (sync vs desync), create a unified umbrella skill rather than two separate narrow skills. The synthesis approach:
1. Frame as a unified framework with dual directions
2. Create comparison table (methods, results, physical systems)
3. Identify common mathematical structures (Lindblad, Keldysh, Arnold tongue)
4. Extract reusable patterns that apply to both directions
5. Reference existing narrow skills, do not replace them
