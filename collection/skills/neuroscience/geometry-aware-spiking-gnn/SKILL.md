# Geometry-Aware Spiking Graph Neural Network

## 概述
几何感知脉冲图神经网络(GA-SGNN)结合脉冲神经网络的能效优势与几何深度学习，通过流形学习尊重脑连接数据的内在几何结构，同时脉冲神经元实现事件驱动计算。

## 核心创新
- 几何感知消息传递：流形嵌入，测地距离，曲率感知
- 脉冲图卷积：事件驱动，稀疏计算，时间维度
- 脑网络特化：功能连接，结构连接，多尺度

## 能效优势
- 能耗仅为标准GNN的10%
- 准确率保持84%
- 效率比8.4x

## 应用场景
- 阿尔茨海默病、帕金森病诊断
- 注意力、工作记忆状态预测
- 儿童脑网络发育分析
- 神经药物效果评估
