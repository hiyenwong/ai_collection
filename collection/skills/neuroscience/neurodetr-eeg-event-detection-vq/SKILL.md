# NeuroDETR — 离散时空多尺度异步 EEG 事件检测

## 核心贡献

针对**异步 EEG 事件检测**（连续记录中同时输出事件类别+起止边界，无预定义窗口），提出三个互相耦合的机制并在 8 个 EEG 数据集（P300/运动想象/运动执行/语音/癫痫）上全面 SOTA（F1_event 平均 46.70，超最强基线 DANCE +4.29pp）：

1. **FOCAL（事件引导稀疏注意力）**：用轻量密度头预测每个窗口的事件存在概率 p_n，只对 p>τ 的窗口做局部自注意力（其余只做背景 LayerNorm），再用轴向注意力跨窗口连接相同 token 位置。事件引导是"计算预算分配"而非硬选择——保留跨窗口上下文。
2. **多尺度时间 VQ**：平均池化（kernel=stride=s）在多个尺度上量化时间特征，各尺度独立码本，插值回最细网格平均后加位置编码形成时间记忆 M_t。粗尺度捕获持续动态、细尺度捕获瞬态响应。
3. **空间金字塔 VQ（跨尺度残差量化）**：在骨干通道混合**之前**，对原始 EEG 通道做三级聚合（1 全头 / 5 脑区 / 12 电极簇），每级量化其相对父级码字的**残差**：ν_1 = E_1；ν_ℓ = E_ℓ − Broadcast(q_{ℓ−1})。门控拼接形成空间记忆 M_s。
4. **DETR 式集合预测**：可学习事件查询 → 时间融合（自注意力+滑窗交叉注意力）→ 门控空间融合（g 初始 0.02 慢启动）→ 4 层 DETR 解码器，并行输出 {(类, 起始, 结束)}，类别 0 = 无事件。

## 架构细节

**骨干**：SimpleConv（Défossez 式）+ 电极坐标 Fourier 嵌入空间注意力混合到 270 个虚拟通道；保持时间分辨率 T 供边界监督。

**FOCAL 路由**：
```
I_evt = {n : p_n > τ} ∪ TopK(ℓ, k_min)   # τ=0.4, k_min=1，保证非空
H̃_n  = MHSA(LN(H_n))  if selected
      = LN_bg(H_n)    otherwise          # 未选中只做背景归一化
```
密度头由 BCE 监督（窗口与标注事件重叠即 y=1），硬路由不回传梯度。密度图与路由掩码在两个 FOCAL 块间共享。

**密度引导空间池化**（Eq.14）：detached 的事件概率插值到 stem 网格后作为三角核加权——强调可能事件时段，不更新密度估计器（sg 断梯度）。

**量化**（VQ 标准）：最近邻码字 + straight-through（Q(z)=z+sg[e_{k*}−z]）；EMA 码本更新+死码重置；承诺损失 β·MSE。重建损失 L_rec 用上采样码字重建 dense 特征（sg[H′]）。

**损失**：DETR 检测损失（匈牙利匹配；L1 边界 + GIoU + 分类）+ 辅助损失（边界 focal、密集分类、预测一致性）+ 密度 BCE + 重建 MSE + 承诺损失。

## 实验结论

- **8/8 数据集 F1_event 第一**；F1_sample 平均 57.50（+3.32 vs DANCE）。
- **低事件占比数据集受益最大**：去掉 FOCAL（M5）在 TUSZ（占空比 3.18%）掉 17.08pp、BNCI2020（27%）掉 13.18pp——事件引导的稀疏计算在稀有事件场景是决定性的。
- **量化×事件引导正交互补**（2×2 消融）：联合配置 8/8 最优；引导使量化收益从 +0.91 提升到 +2.97pp（平均交互对比 2.06pp）。机理：事件引导让码本只对事件相关特征分配容量。
- **空间金字塔的跨级残差是必要的**（M4 去掉后 HDOP −4.95、TUSZ −8.76）。
- 基线：EventNet、ActionFormer、DyFADet、DOSED（密集检测）+ DANCE（查询集合预测）+ Random；评估用 1-1 匹配、IoU>0.5、类一致才计 TP。

## 方法论要点（可移植模式）

1. **异步事件检测范式选择**：滑动窗口分类 → 碎片化/合并事件；查询式集合预测（DETR）一步解决变长边界——任何"连续信号中检测不定长事件"的任务（睡眠分期转角、心律失常点检测、日志异常段）都适用。
2. **密度引导稀疏注意力**：先用廉价头预测"哪里有事件"，再对高概率窗口做昂贵注意力——低占空比信号（癫痫、稀疏 ERP）的通用效率模式。TopK 兜底防全空。
3. **金字塔残差 VQ**：逐级量化"相对父级码字的残差"避免各级码本重复编码粗结构——可移植到任何层级特征量化（语音、视频）。
4. **通道混合前的空间金字塔**：在骨干把电极信息抹平之前，先按解剖学分组（额/颞/中央/顶/枕）聚合量化——空间先验显式保留。
5. **门控融合慢启动**（g=σ(γ) 初始 0.02）：辅助分支（空间流）不干扰主分支早期训练——通用多分支融合技巧。
6. **离散码本=可解释事件词典**：码字在事件相关特征上分配容量，天然形成跨数据集可复用的"事件原语"库。

## 陷阱

- FOCAL 的密度头训练信号（窗口级 BCE）与最终目标（事件级 F1）不同——密度图偏差会直接误导稀疏路由；需要 detached 引导+独立监督来稳定。
- 硬路由下未选中窗口无梯度——必须保 TopK(k_min) 和密度 BCE，否则密度头退化。
- 空间金字塔依赖**电极命名约定**（按通道名分组）；非标准蒙太奇数据集需要先做电极聚类。
- TUSZ（长时癫痫）是单结果报告（非交叉验证）；长窗（3600s）内存开销来自轴向注意力的窗口数平方增长。
- VQ 训练不稳定性由 EMA+死码重置缓解，但低占空比数据上码本利用率仍依赖事件引导加权。

## 应用场景

- **实用 BCI**：免触发连续解码（P300 拼写器无需固定 epoch、MI/ME 控制无需提示锁定）。
- **临床监测**：癫痫发作自动定位（TUSZ）、术中监护异常段检测。
- **神经科学流水线**：自动 ERP 标注替代人工分段；跨范式统一检测器。
- **相邻领域移植**：睡眠纺锤波/K复合波检测、心电异常段、可穿戴设备长时监测。
