# Untrained CNNs Match Backpropagation at V1: RSA Comparison of Learning Rules

## Overview
Systematic comparison of four learning rules (backpropagation, feedback alignment, Hebbian learning, untrained) against human fMRI V1 responses using Representational Similarity Analysis (RSA).

Based on: [Untrained CNNs Match Backpropagation at V1: A Systematic RSA Comparison of Four Learning Rules Against Human fMRI](https://arxiv.org/abs/2604.16875) (2026-04-18)

## Abstract
We systematically compare four learning rules (backpropagation, feedback alignment, Hebbian learning, untrained networks) against human fMRI V1 responses using Representational Similarity Analysis (RSA). Surprisingly, untrained CNNs match backpropagation at V1 level, suggesting that learning rule may not determine cortical alignment at early visual areas.

## Methodology

### RSA Comparison Methodology
- Representational Similarity Analysis (RSA) for brain-model comparison
- Four learning rules: Backpropagation, Feedback Alignment, Hebbian, Untrained
- Compare against human fMRI V1 responses
