# LLM-Neuroscience Intersection (2026)

## Overview
A comprehensive survey exploring the intersection of Large Language Models (LLMs) with brain and cognitive sciences. Covers how LLMs align with brain activity, how they can model cognition, and how neuroscience can inspire better AI architectures.

## Key Research Directions

### 1. LLM-Brain Alignment
- **Neural predictivity**: How well do LLM representations predict brain activity (fMRI, EEG, MEG)?
- **Layer-to-region mapping**: Which LLM layers correspond to which brain regions?
- **Alignment metrics**: RSA (Representational Similarity Analysis), encoding models
- **Training effects**: How does pretraining/fine-tuning affect brain alignment?

### 2. Cognitive Modeling with LLMs
- **Language processing**: LLMs as models of human language comprehension
- **Reasoning**: Can LLMs model human reasoning patterns?
- **Memory**: LLM context windows vs. working memory systems
- **Attention**: Transformer attention vs. biological attention mechanisms

### 3. Brain Decoding with LLMs
- **Text reconstruction**: Decoding perceived/read text from brain activity
- **Thought decoding**: Reconstructing internal thoughts from neural signals
- **Multimodal decoding**: Combining language and visual brain decoding
- **Clinical applications**: Communication for locked-in patients

### 4. Neuroscience-Inspired Architectures
- **Biological plausibility**: Making LLMs more brain-like
- **Sparse connectivity**: Brain-like sparse vs. dense transformer connections
- **Neuromodulation**: Adding dopamine-like reward signals
- **Local learning**: Replacing backpropagation with local plasticity rules

## Technical Frameworks

### Alignment Methods
- **Encoding models**: Linear/nonlinear mapping from LLM features to brain activity
- **Decoding models**: Predicting stimuli/semantics from brain activity
- **RSA**: Comparing representational geometry between LLMs and brains
- **In-context alignment**: Using task context to improve alignment

### Evaluation Metrics
- **Neural predictivity**: Correlation between predicted and actual brain activity
- **Behavioral alignment**: How well LLMs predict human behavior
- **Cognitive plausibility**: Does the model process information like humans?
- **Brain score**: Composite metric of brain-likeness

## Key Findings

### What LLMs Capture Well
- Hierarchical language processing in temporal cortex
- Semantic representations in higher-order brain regions
- Context-dependent processing patterns
- Some aspects of reasoning and inference

### What LLMs Miss
- Multimodal integration (vision, audition, proprioception)
- Embodied cognition and sensorimotor grounding
- Emotional and social processing
- Metacognition and self-awareness
- Energy-efficient sparse computation

## Applications

### Primary Uses
1. **Cognitive neuroscience**: Using LLMs as computational models of cognition
2. **Brain-computer interfaces**: LLM-enhanced brain decoding
3. **AI safety**: Understanding LLM cognition through brain comparison
4. **Neurological disorders**: Modeling language deficits (aphasia, dementia)
5. **Education**: Understanding how humans learn language vs. LLMs

### Research Questions
- Do LLMs process language like the human brain?
- Can LLMs serve as null models for brain activity?
- What brain-like modifications improve LLM performance?
- How can brain data guide LLM architecture design?

## Implementation Considerations

### Data Requirements
- Neural data: fMRI, EEG, MEG, ECoG recordings
- Stimulus materials: Text, images, audio used during recording
- Behavioral data: Human responses for validation

### Computational Requirements
- LLM inference for feature extraction
- Encoding/decoding model training
- Cross-validation across subjects and stimuli
- Statistical testing for alignment significance

### Key Challenges
- **Temporal mismatch**: LLMs are static, brains are dynamic
- **Scale mismatch**: LLMs have billions of parameters, brains have ~86B neurons
- **Training mismatch**: LLMs trained on text, brains on multimodal experience
- **Interpretability**: Understanding what LLM layers represent
