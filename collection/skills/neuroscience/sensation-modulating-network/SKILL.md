# Sensation Modulating Network (SMN)

## Core Framework

The SMN proposes a complete embodied cognitive architecture built on three foundational principles:

1. **Haltability** - Recruitment of antagonistic affordance into co-activated equilibrium
2. **Dual-Signal Property** - Self/world distinction as structural wiring feature
3. **Four-Level Action Pattern Hierarchy** - Trajectory from autonomic to conventional

### Key Innovation: Haltability as Architectural Ground

**Chain of emergence:**
```
Opponency → Co-activation → Halt → Attention → Intentional Directedness
```

No module added on top - intentional directedness emerges from architectural substrate itself.

## Sensation Modulators (SMs)

**Definition:** Units that sense and act through one substrate, paired into Coordinated Action Zones (CAZs).

**Key Properties:**
- Single substrate for sensing and acting (no separation)
- Routed by body-wide broadcast network
- Organized at every anatomical scale
- Opponent dynamics throughout

## Self-Modulatable Action Patterns (SMAPs)

**Dual-Signal Property:**
- Structural feature of wiring (not applied category)
- Self/world distinction inherent in architecture
- Eliminates need for external self/world concept

## Four-Level Action Pattern Hierarchy

1. **Basal Action Patterns** - Autonomic regularity (homeostatic)
2. **Haltable Action Patterns** - Co-activation enables halt
3. **Negotiable Action Patterns** - Recursion lives here (modifiable dynamics)
4. **Transactional Action Patterns** - Public conventionalization

**Critical insight:** Grammar-grounded generativity emerges from architectural transitions, not added modules.

## Reconciliation of Cognitivism-4E Debate

**Traditional split:**
- **Cognitivism:** Accounts for recursion and language but cannot ground symbols in meaning
- **4E approaches:** Grounds cognition in body but lacks generativity specification

**SMN resolution:**
- **Recursion:** Lives in modifiable dynamics of Negotiable Action Patterns
- **Embodiment:** In opponent substrate that supports them
