# Uncommon Self-Knowledge (USK) Consciousness Theory Framework

## Core Idea

Defines **consciousness** as **synergistic information** a system carries about its own state. This information only exists in the joint of subsystems and is **destroyed by decomposition**.

## Theoretical Foundation

### Partial Information Decomposition (PID)

- **Redundancy** corresponds to Aumann common knowledge (each subsystem can independently access)
- **Synergy** is information accessible only from joint observation, lost upon decomposition
- **USK** equals self-directed synergy: the synergistic component of information about the system own state

### Resolving Counterexamples

| Theory | Problem | USK Resolution |
|--------|---------|----------------|
| IIT | Photodiode has non-zero Phi | USK is zero for simple systems with no self-synergy |
| GWT | Timing of global broadcast | USK predicts temporal dissociation from broadcast |
| HOT | Higher-order is not consciousness | USK separates metacognition from consciousness |

## Methodology: PIRD with Self-Targeting

### The Formula

```
USK = Syn(X_1, X_2, ..., X_n to System_State)
```

Where Syn is the synergistic information component from PID, and X_i are subsystems.

### Operational Steps

1. **Define subsystem partition** - decompose the system into meaningful subcomponents
2. **Build joint distribution** - record subsystem activity correlated with system state
3. **Compute PID decomposition** - decompose into redundant, unique, and synergistic components
4. **Extract synergy** - self-directed synergy equals USK measure
5. **Perturbation validation** - verify synergy vanishes when system is decomposed

### Empirical Predictions

- **GWT timing dissociation**: Global broadcast and information integration can temporally dissociate
- **LLM perturbation effects**: Submodule perturbation of LLMs should reduce measurable synergy
- **Consciousness-metacognition split**: USK distinguishes consciousness from metacognitive ability

## Key Insights

1. **Consciousness is not Information Integration**: IIT Phi includes redundant info; USK isolates only synergy
2. **Decomposition destroys consciousness**: Self-directed synergistic information necessarily vanishes on decomposition
3. **Operationalizable**: PIRD provides a concrete computational path
4. **Cross-platform applicable**: From biological brains to LLMs
