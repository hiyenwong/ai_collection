## Abstract
This paper uses multilingual LLMs to create "computational lesions" for studying brain-model alignment. By zeroing parameter sets that are important across languages or specific to individual languages, the study creates targeted lesions that separate shared processing from language-specific processing, establishing a causal framework for brain-model alignment.

## Key Contributions
1. Computational lesion methodology using multilingual LLMs
2. Separation of shared core vs language-specific mechanisms
3. Causal analysis framework for brain alignment
