# Task-Specific Programming of Chaos in Neural Circuits

**arXiv**: 2605.19465 (nlin.CD, physics.comp-ph)
**Authors**: Jungyoon Kim, Kyuho Kim, Kunwoo Park, Namkyoo Park, Sunkyu Yu

## Core Methodology

Demonstrates **programmable chaotic dynamics** for task-specific reservoir computing by tuning **network topology** as a design freedom, not just element-level parameters.

### Key Mechanism

- **Network topology control** drives ordered-to-chaotic transition
- Accompanied by transitions in correlation timescales, stability, and signal propagation
- **Small-world connectivity** enables low-latency on-off switching of chaos via edge rewiring

### Unified Chaos-Latency Phase Diagram

Joint control of element-level properties + network topology reveals a phase diagram showing:
- Where chaos can be switched on/off rapidly
- How topological regimes affect computational capability
- Optimal regimes for different reservoir computing tasks

### Design Principle

**Topology as reconfigurable parameter**: Network structure serves as a tunable control knob for task-specific computation, complementing traditional parameter tuning.

## Implementation Patterns

- Control chaos via network topology (not just node parameters)
- Use small-world connectivity for rapid chaos switching
- Build chaos-latency phase diagrams for task optimization
- Combine element-level and topological control for unified tuning
- Apply to reservoir computing, random number generation, probabilistic inference

## Applications

- Neuromorphic computing with tunable complexity
- Reservoir computing with adaptive dynamics
- Random number generation from physical chaos
- Probabilistic inference hardware
- Classical analogues of quantum randomness
