# CD-QAOA Portfolio Optimization

Constrained Counterdiabatic Quantum Approximate Optimization Algorithm for portfolio selection problems.

## Core Methodology

CD-QAOA extends standard QAOA by incorporating counterdiabatic (CD) driving terms — approximate adiabatic gauge potentials generated by variational quantum circuits — to accelerate convergence and improve constraint satisfaction.

### Why CD-QAOA over Standard QAOA

| Metric | Standard QAOA | CD-QAOA |
|--------|--------------|---------|
| Circuit depth | Higher | Reduced by ~30-50% |
| Constraint satisfaction | Penalty-based | CD-driven |
| Approximation ratio | Slower convergence | Faster to target ratio |
| Real-world datasets | Suboptimal | Better solutions |

## Implementation Pattern

### Step 1: Problem Formulation

Convert portfolio optimization to constrained QUBO:

```
minimize: x^T Q x  (risk-return tradeoff)
subject to:
  Σ x_i = K           (cardinality constraint)
  Σ w_i x_i = B       (budget constraint)
  x_i ∈ {0, 1}        (binary selection)
```

Key components:
1. **Problem Hamiltonian (H_P)**: Encodes portfolio objective + constraints
2. **Mixer Hamiltonian (H_M)**: Drives exploration (typically X-mixer)
3. **Gauge Potential (A)**: Approximate AGP via variational circuit
4. **Schedule functions s(t), α(t)**: Annealing schedules

### Step 3: Variational Gauge Potential Optimization

```
For each CD-QAOA layer:
  1. Initialize variational parameters θ for AGP ansatz
  2. Minimize Frobenius norm: ||[H(t), A_θ] - ∂_t H||
  3. Optimize QAOA angles (γ, β) with CD terms
  4. Iterate until convergence
```

### Step 4: Constraint Handling

CD-QAOA handles constraints natively through counterdiabatic driving:
- No penalty coefficients needed
- Constraints embedded in gauge potential
- Better feasibility rates than penalty methods

## When to Use

- **Constrained portfolio optimization** with cardinality/budget limits
- **QUBO problems** where standard QAOA converges slowly
- **NISQ-era quantum computers** where circuit depth is critical
- **Real-world financial datasets** requiring constraint satisfaction

## Parameters

| Parameter | Description | Typical Value |
|-----------|-------------|---------------|
| p (depth) | QAOA circuit depth | 2-6 |
| α | CD driving strength | Learned variationally |
| K | Cardinality constraint | User-defined |
| B | Budget constraint | User-defined |
