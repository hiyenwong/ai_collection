# Quantum Spectroscopy with Undetected Photons for Biomolecular Sensing

## Description

Quantum spectroscopy technique using undetected photons for protein detection in the mid-infrared spectral region. Provides advantages over classical FTIR spectroscopy through quantum interference and heralded detection schemes.

## Activation Keywords

- quantum spectroscopy undetected photons

- quantum-enhanced IR sensing

## Core Methodology

### Quantum Spectroscopy Principle

Uses entangled photon pairs where:
1. **Signal photon** interacts with sample (mid-IR)
2. **Idler photon** is detected (visible/near-IR)
3. Sample information is inferred from idler correlations
4. The interacting photon is never directly detected

### Key Advantages over Classical FTIR

| Aspect | Classical FTIR | Quantum Spectroscopy |
|--------|---------------|---------------------|
| Detection | Direct IR detection | Visible photon detection |
| Noise | Thermal background | Quantum-limited |
| Resolution | Limited by source | Enhanced via correlation |
| Sample damage | Direct IR exposure | Lower energy per detection |

### Implementation Steps

1. **Setup**: SPDC source for entangled photon pairs
2. **Sample interaction**: Signal photon passes through protein sample
3. **Heralded detection**: Idler photon detection heralds successful interaction
4. **Spectrum reconstruction**: Build spectrum from coincidence counts
5. **Comparison**: Validate against classical FTIR reference measurements

## When to Use

1. **Protein structure analysis**: Mid-IR fingerprint region (2.5-25 μm)
2. **Low-concentration samples**: Quantum enhancement for weak signals
3. **Sensitive biological samples**: Reduced exposure vs classical methods
4. **Spectral fingerprinting**: Biomolecular identification via IR signatures
