# Learning to See Before Seeing: Demystifying LLM Visual Priors from Language Pre-training

## Abstract

LLMs develop rich visual priors despite text-only training. We reveal that visual priors are composed of separable perception and reasoning priors with unique scaling trends and origins. Visual reasoning ability is predominantly developed by pre-training on reasoning-centric data (code, math, academia). We propose a data-centric recipe for pre-training vision-aware LLMs verified in 1T token scale pre-training across 100+ controlled experiments consuming 500,000 GPU-hours.
