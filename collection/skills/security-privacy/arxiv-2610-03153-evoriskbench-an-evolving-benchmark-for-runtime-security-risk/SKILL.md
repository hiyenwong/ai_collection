# EvoRiskBench: An Evolving Benchmark for Runtime Security Risks in Workspace Agents

**arXiv:** [2610.03153](https://arxiv.org/abs/2610.03153)
**Authors:** Anonymous
**Categories:** cs.AI; cs.CR; cs.SE
**Utility Score:** 0.87

## Abstract

Workspace agents combine large language models with execution harnesses to perform stateful, multi-step tasks that access or modify external resources. We introduce EvoRiskBench, an evolving benchmark organized around the EP-Path-EF framework, which links an initial risk entry point to a one-hop technical effect through an agent-mediated risk path. The benchmark provides a reproducible dataset of 450 adversarial tasks across six scenarios. We evaluate nine Model x Harness configurations. The most vulnerable configuration reaches a 68.44% attack success rate.
