# Optimizing Privacy-Preserving Primitives to Support LLM-Scale Applications

## Abstract

We present an overview of efforts to bridge the gap between overhead and practicality for privacy-preserving learning systems using MPC, ZKPs, and FHE. Through hardware/software/algorithm co-design, we show progress towards enabling LLM-scale applications in privacy-preserving settings including DNN IP ownership, ethical LLM usage enforcement, and transformer inference.
