## Core Discovery

**Universal organizational regularity**: In every complex system studied (biological, ecological, social, technological), real interaction strengths organize memory at greater hierarchical depths than topology alone.

## Key Insight

Functional memory in complex systems depends on **weight geometry** (interaction strength distribution), not just **topology** (connection structure).
