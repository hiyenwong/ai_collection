# Multi-VQC Healthcare

## Description
Multi-Variational Quantum Circuit (Multi-VQC) methodology for enhancing healthcare classification tasks with significant class imbalance. Based on arXiv:2505.20797. Uses multiple VQC modules to map data into higher-dimensional quantum feature spaces, overcoming classical model limitations on imbalanced datasets.
