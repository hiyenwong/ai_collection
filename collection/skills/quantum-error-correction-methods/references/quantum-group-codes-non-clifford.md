# Quantum Group Codes for Non-Clifford Logic (arXiv: 2606.27211, June 2026)

## Paper Summary
Gasnier & Guémard define quantum CSS codes from classical quasi group codes supporting transversal multi-control-Z gates with both addressability and parallelizability.

## Key Results

### Construction
- Input: good quantum AG code over F_q with transversal C^m Z gate
- Lifting: class field theory lifting of underlying classical AG code
- Output: quantum group code over F_{q²} with transversal C^m Z + parallelizable C^{m-1}Z

### Decoding Improvement
- **Quasi-quadratic**: O(n² log n) vs O(n³) cubic for previous quantum AG codes
- Linear decoding radius
- ~linear speedup in magic state distillation time complexity

### Gate Support
- Transversal C^m Z (addressable)
- Parallelizable C^{m-1}Z gates
- Efficient non-Clifford gate circuits at logical level
