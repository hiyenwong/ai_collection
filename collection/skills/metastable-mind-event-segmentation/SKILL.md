# Metastable Mind: Neural Underpinnings of Naturalistic Cognition

## Core Concept

Unified framework bridging Event Segmentation (ES) cognitive theory and Metastable Neural Activity (MNA) mechanistic approach - demonstrating both study the same metastable neural states from different perspectives.

## Key Principles

### 1. Spatio-Temporally Nested Hierarchy
- Longer-duration states in higher-order regions constrain and shape states in faster-operating regions
- Temporal hierarchy: slow (seconds-minutes) ↔ fast (milliseconds)
- Spatial hierarchy: prefrontal ↔ sensory-motor regions
- Top-down constraints + bottom-up influences

### 2. Predictive Models Reflection
Neural states reflect underlying predictive models that shape:
- **Perception**: active inference from sensory inputs
- **Decision making**: evidence accumulation in stable states
- **Memory encoding**: consolidation during stable periods
- **Memory recall**: state transitions trigger retrieval

### 3. Modular Processing Intervals
- Stable neural states = periods of modular processing
- State boundaries = connectivity reconfiguration
- Segmentation events = network reorganization
- Information integration peaks at boundaries

## Metastable Neural States as Computational Units

### Fundamental Properties
1. **Duration**: 100-500ms typical, hierarchy-dependent
2. **Stability**: within-state coherence > between-state transitions
3. **Content**: encoding task-relevant information
4. **Boundaries**: rapid transitions (20-50ms)

### Computational Role
- **State = discrete cognitive unit**
- **Transition = information integration**
- **Hierarchy = multi-scale processing**
- **Prediction = state anticipation**

## Event Segmentation Framework

### Behavioral Evidence
- Continuous experience → discrete events
- Event boundaries = natural segmentation points
- Segmentation aids comprehension, memory, decision-making
- Subjective perception aligns with neural transitions

### Cognitive Utility
- **Online comprehension**: chunking for efficiency
- **Memory organization**: hierarchical storage structure
- **Decision frames**: bounded deliberation periods
- **Narrative construction**: event chaining

## Neural Implementation

### Metastable Dynamics
- **Attractor landscapes**: stable states as attractors
- **Criticality**: poised for rapid transitions
- **Variability**: state diversity = computational richness
- **Ergodicity breaking**: non-random state sequences

### Brain Regions
- **Prefrontal cortex**: slow, abstract states
- **Sensory areas**: fast, concrete states
- **Hippocampus**: event memory encoding
- **Parietal cortex**: boundary detection

## Methodology Patterns

### 1. State Detection
```
# Metastable state identification from neural recordings
1. Compute population activity vectors
2. Identify stable periods (low variance)
3. Detect rapid transitions (high variance)
4. Map state sequences to task phases
5. Validate with behavioral segmentation reports
```

### 2. Hierarchy Analysis
```
# Multi-scale state hierarchy reconstruction
1. Extract state durations across regions
2. Build temporal hierarchy tree
3. Test top-down constraints (Granger causality)
4. Verify bottom-up influences (information flow)
5. Quantify hierarchical nesting strength
```

### 3. Boundary Characterization
```
# State boundary feature extraction
1. Identify transition timing
2. Measure connectivity changes (graph metrics)
3. Compute information integration peaks
4. Correlate with behavioral event reports
5. Predict next-state probabilities
```

### 4. Predictive Model Mapping
```
# Neural states → predictive models linkage
1. Decode state content (representation analysis)
2. Identify prediction errors at boundaries
3. Measure evidence accumulation trajectories
4. Test memory encoding efficiency per state
5. Validate retrieval trigger at transitions
```

## Pitfalls & Common Errors

1. **Oversimplified state models** - States are hierarchical, not flat
2. **Ignoring boundaries** - Transitions carry critical information
3. **Behavioral-neural mismatch** - Segmentation reports ≠ neural states exactly
4. **Single-scale analysis** - Miss hierarchy without multi-scale methods
5. **Static connectivity** - Boundaries reconfigure networks dynamically
6. **Pure attractor view** - States are metastable, not perfectly stable
7. **Deterministic transitions** - Probabilistic, not fixed sequences
