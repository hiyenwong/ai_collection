# Paper Reference: EEG-FM-Audit

## Source
- **arXiv ID**: 2605.26910
- **Title**: EEG-FM-Audit: A Systematic Evaluation and Analysis Pipeline for EEG Foundation Models
- **Authors**: Xianheng Wang, Yige Yang, Damien Coyle
- **Submission Date**: May 26, 2026
- **URL**: https://arxiv.org/abs/2605.26910

## Key Contributions

1. **ASHA Benchmarking Protocol** - Transparent hyperparameter optimization for supervised baselines
2. **Paradigm Ablation Framework** - Evaluates SSL, contrastive, transfer, multitask learning
3. **Neurophysiological Probing (NPP)** - Validates temporal, spatial, spectral EEG features

## Core Findings

- Properly tuned supervised baselines match/outperform FMs with fewer parameters
- Paradigm effectiveness depends on dataset scale and architecture
- FMs rely on specific physiological features (validated via NPP)
