# QML Paper-to-Skill Extraction Guide

## When Extracting from QML Papers
Today's session extracted 3 skills from quantum machine learning papers. Key patterns:

### QML Theory Papers → Framework Skills
- Papers proving impossibility theorems or theoretical bounds → create "framework" skills
- Extract the theoretical framework as actionable decision procedures
- Include both the mathematical result AND the practical implications for QML design
- Example: "No Reference-Free Generalization" → framework for reference-based QML protocol design

### QML Engineering Papers → Optimization Skills
- Papers proposing new methods/techniques → create "optimization" skills
- Focus on the specific engineering problem solved and the proposed solution
- Include the validation results as evidence of effectiveness
- Example: "ML QEC Threshold Optimization" → ML-guided search for QEC parameters

### QML Architecture Papers → Computing Skills
- Papers introducing new architectures → create "computing" skills
- Document the architecture components and how they differ from existing approaches
- Include hybrid quantum-classical patterns when applicable
- Example: "Quantum Hyperdimensional Computing" → quantum-enhanced vector space computation

### Extraction Checklist for QML Papers
1. **Core Innovation**: What's the new method/technique/theory?
2. **Problem Domain**: What specific QML problem does it address?
3. **Validation**: How was it validated? (simulations, hardware, theory)
4. **Practical Impact**: How does this change QML practice?
5. **Activation Keywords**: What queries would trigger this skill?
6. **Related Skills**: What existing QML/quantum skills does this connect to?

### Common QML Skill Categories
- **quantum-ml-patterns**: General QML methodology patterns
- **quantum-error-correction-methods**: QEC-related skills
- **quantum-neural-network-designer**: QNN architecture skills
- **quantum-learning-theory**: Theoretical QML foundations
- **quantum-optimization**: Quantum optimization algorithms
