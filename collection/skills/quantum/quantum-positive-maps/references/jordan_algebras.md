# Jordan Algebras in Quantum Information

## Jordan Algebra Definition

### Jordan Product

```
A ◦ B = (AB + BA)/2
```

Properties:
- **Commutative**: A ◦ B = B ◦ A
- **Power-associative**: A ◦ (A ◦ A) = (A ◦ A) ◦ A
- **NOT associative** in general

### Jordan Algebra

Set J closed under Jordan product ◦ with additional axioms:
```
(A ◦ B) ◦ (A ◦ A) = A ◦ (B ◦ (A ◦ A))  (Jordan identity)
```

## Quantum Connection

### Operator Jordan Algebras

For Hilbert space H, Jordan algebra of operators:
```
J = {A : A† = A, closed under ◦}
```

Self-adjoint operators form Jordan algebra.

### Observables

Quantum observables: Jordan algebra elements
```
O = {A : A† = A}
```

Measurement statistics determined by Jordan structure.

### State Space

States: Linear functionals ω on Jordan algebra
```
ω(A) = Tr[σ A]  for density matrix σ
```

## Jordan vs *-Algebra

### *-Algebra

Closed under both:
- Jordan product: A ◦ B = (AB + BA)/2
- Associative product: AB

### Jordan Subalgebra

Closed under Jordan product only:
- Contains observables
- May not contain all operators

### Minimal Sufficient Jordan Algebra

For PTP map Φ and state family {σ_i}:
```
J_min = smallest Jordan algebra that determines sufficiency
```

Generated by Neyman-Pearson test operators.

## Special Jordan Algebras

### Hermitian Matrices

J_n = {A ∈ C^{n×n} : A† = A}

Jordan product: Hermitian matrices closed under ◦

### Quantum Spin Systems

For N spins: Jordan algebra of local observables
```
J_local = {A : A acts on ≤ k sites, A† = A}
```

### Factor Types

Type I, II, III Jordan algebras (von Neumann algebra classification)

## Applications

### 1. Quantum Measurement

Observable algebra → Jordan algebra
- Measurements respect Jordan structure
- POVM elements: Jordan algebra elements

### 2. Quantum Channels

Channel preserves Jordan structure if:
```
Φ(A ◦ B) = Φ(A) ◦ Φ(B) for all A, B ∈ J
```

### 3. State Discrimination

Neyman-Pearson tests:
```
T = argmax P(correct) under constraints
```

Test operators T generate minimal Jordan algebra.

## Mathematical Results

### Jordan-von Neumann-Wigner Theorem

Classification of finite-dimensional simple Jordan algebras:
1. Full matrix algebras M_n(R), M_n(C), M_n(H)
2. Quaternion matrices
3. Albert algebra (27-dimensional exceptional)

### Gelfand-Naimark-Segal (GNS) for Jordan

State ω on Jordan algebra J → representation:
```
J ↪ B(H_ω)
```

Jordan algebra represented as operators on Hilbert space.
