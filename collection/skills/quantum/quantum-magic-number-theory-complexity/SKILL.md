# Quantum Magic and Number-Theoretic Complexity

## Core Insight

The execution cost of quantum algorithms should not be measured solely by
asymptotic gate counts and qubit registers. The genuinely quantum resources
that must be created and maintained — particularly **non-stabilizerness (magic)** —
are the true bottleneck for fault-tolerant quantum computing.

For number-theoretic algorithms like Shor's factoring, there is a deep
connection between:
- **Classical hardness**: The computational difficulty of the underlying 
  number-theoretic problem (integer factoring, discrete logarithm)
- **Quantum resource cost**: The amount of magic (non-stabilizerness) that 
  must be generated and maintained during computation

## Key Concepts

### Magic (Non-Stabilizerness)
- Quantum states outside the stabilizer polytope
- Essential resource for quantum advantage
- Generated by non-Clifford gates (T-gates, arbitrary rotations)
- Quantified via robustness of magic, stabilizer extent, or mana

### Resource-Aligned Complexity
- Instead of counting gates, count **magic states consumed**
- Shor's routine maximally exploits quantum resources in practically relevant regimes
- The magic cost correlates with the number-theoretic hardness of the problem

### Methodology

1. **Identify the non-stabilizer operations**: Which gates generate magic?
   - T-gates, Toffoli gates, arbitrary-angle rotations
   - Each contributes to the total magic budget

2. **Quantify magic generation**: Use metrics like:
   - Robustness of Magic (RoM): minimum mixing with stabilizer states
   - Mana: log of sum of absolute Wigner function values
   - Stabilizer extent: optimal decomposition into stabilizer states

3. **Link to classical hardness**: 
   - Harder number-theoretic instances require more magic
   - The magic cost reflects the information-theoretic requirement
   - Provides a resource-based metric aligned with real FTQC bottlenecks

4. **Evaluate against standard metrics**:
   - Compare magic cost vs gate count vs qubit count
   - Identify which metric best predicts actual execution difficulty

## Applications

- **Shor's algorithm analysis**: Link factoring difficulty to magic cost
- **Resource estimation for quantum cryptography**: Assess security margins
- **Algorithm comparison**: Evaluate quantum algorithms by resource consumption
- **FTQC bottleneck identification**: Magic state distillation as the true cost driver
