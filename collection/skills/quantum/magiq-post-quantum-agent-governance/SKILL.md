# MAGIQ: Post-Quantum Multi-Agent AI Governance

Policy definition and enforcement framework for multi-agent AI systems using
quantum-resistant cryptographic protocols with provable security guarantees.

## Paper

arXiv: 2605.06933v1 — *MAGIQ: A Post-Quantum Multi-Agentic AI Governance
System with Provable Security* by Sepideh Avizeh, Tushin Mallick,
Alina Oprea, Cristina Nita-Rotaru, Reihaneh Safavi-Naini (May 2026).

## Core Capabilities

1. **Policy Definition**: Rich communication and access-control policy budgets
   for agent-to-agent sessions, including global one-to-many budgets.
2. **Post-Quantum Enforcement**: Policies enforced using PQC primitives
   (NIST-recommended, replacing RSA/DH/ECC by 2035).
3. **Session-Based Enforcement**: Agent-to-agent and one-to-many session policies.
4. **Accountability**: Message attribution ensuring agents are accountable to users.

## Security Model

- Formal correctness and security proofs using the Universal Composability (UC) framework
- Computation and communication overhead evaluated against SAGA baseline
- First post-quantum-secure solution for agentic AI systems

## When to Use

- Designing secure multi-agent AI architectures
- Implementing post-quantum cryptography for agent communication
- Building accountability mechanisms for agentic systems
- Comparing governance frameworks (SAGA vs MAGIQ)
