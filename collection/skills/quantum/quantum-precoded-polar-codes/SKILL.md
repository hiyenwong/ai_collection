# Quantum Precoded Polar Codes

## Description

Quantum Precoded Polar Codes introduce a new family of CSS codes obtained from rate-1 precoded polar codes, harnessing precoding benefits from classical short blocklength polar codes. Uses genetic algorithm to optimize rate profile and precoder, presenting codes of dimension 256 with improved logical error rates. Bridges classical coding theory with quantum error correction.
