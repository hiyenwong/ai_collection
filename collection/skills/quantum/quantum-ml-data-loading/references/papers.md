# Quantum ML Data Loading - Key Papers

## Foundational Papers

### State Preparation

1. **Quantum state preparation with optimal circuit depth**
   - arXiv: 2004.08469
   - Authors: Möttönen et al.
   - Key result: O(n) depth for n amplitudes

2. **Efficient quantum circuits for state preparation**
   - arXiv: 1807.03206
   - Focus: Sparse state preparation

3. **Synthesis of quantum superpositions for data loading**
   - arXiv: 0407010
   - Early work on amplitude encoding

### Feature Maps

4. **Quantum feature maps for machine learning**
   - arXiv: 1804.11326
   - Authors: Havlíček et al.
   - Foundation of quantum kernels

5. **Supervised learning with quantum computers**
   - arXiv: 1707.05391
   - Authors: Farhi & Neven
   - Early QML with data encoding

### NISQ Optimizations

6. **Approximate quantum state preparation**
   - Various works on trading accuracy for depth

7. **Hardware-aware circuit compilation**
   - Qiskit transpilation strategies
   - Gate optimization for connectivity

## Recent Developments (2023-2024)

- Quantum data loaders with reduced depth
- Learned encoding strategies
- QRAM implementations
- Error mitigation for state preparation
