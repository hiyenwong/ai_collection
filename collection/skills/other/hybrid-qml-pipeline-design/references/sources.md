# Research Sources

## Papers Analyzed (2026-05-06)

### Noise Effects in Hybrid QML (Bose & Faryad, 2026-04-13)
- Systematic study of combined classical + quantum noise
- Classical noise (speckle, impulse, quantization, dropout) amplifies quantum decoherence
- Key finding: evaluate noise holistically, not in isolation
- ZZ feature map with Qiskit Aer noise channels

### VQA Review: Fault-Tolerant Path (Wang et al., 2026-04-09)
- VQAs central in NISQ era, transitioning to EFT and FT regimes
- Barren plateaus: primary training bottleneck
- Ansätze design + classical optimization strategy critical
- Roadmap: NISQ → EFT (error mitigation + partial correction) → FT

### Domain-Aware Hybrid Quantum Learning (Das et al., 2026-04-08)
- Correlation-guided circuit design for structured data
- QAOA achieves 84.6% accuracy with fewer parameters than classical baselines
- Four paradigms: quantum, classical baseline, two hybrid architectures
- Practical for resource-constrained edge deployment

### QCNN for Entanglement Classification (Elhag & Chai, 2026-04-07)
- Compact 4-qubit QCNN outperforms larger models
- Encoding choice > model scaling
- Faster convergence and lower variance than classical CNN

### Quantum Random Forest (Khadiev & Safina, 2026-03-24)
- Quantum algorithm for Random Forest regression testing
- Superior query complexity vs classical counterpart

### TensorCircuit-NG (Zhang et al., 2026-02-15)
- Unified platform: quantum circuits + tensor networks + neural networks
- JAX/TF/PyTorch backends, distributed computing support
- Near-linear speedup on GPU clusters for distributed VQAs

### openQSE Reference Architecture (Shehata et al., 2026-04-22)
- Analyzes 9 production QHPC stacks
- Layer boundaries for interoperable quantum-HPC ecosystem
- Supports NISQ and FTQC without upper-layer API changes

### Molecular Property Prediction Survey (Li et al., 2026-04-17)
- Four paradigms: Quantum, Descriptor ML, Geometric DL, Foundation Models
- Physics-aware learning with quantum consistency
- Uncertainty-calibrated foundation models
