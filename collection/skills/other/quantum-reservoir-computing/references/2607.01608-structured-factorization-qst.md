# arXiv:2607.01608 - Structured Factorization for Quantum State Tomography

## Key Contribution
Unified framework termed "structured factorization" that builds on Burer-Monteiro-type factorization by parametrizing density matrix as FF†, where factor F is constrained to belong to a structured model class.

## Core Results
- Guarantees physical validity (positive semidefiniteness) by construction
- Enables broad range of structural priors: Cholesky, low-rank, matrix product states, tensor train, neural network representations
- Scalable in both sample complexity and parameter complexity

## Implementation Pattern
```
ρ = FF†
F ∈ structured model class
where model class can be:
- Low-rank matrices (r << d)
- Matrix Product States (MPS)
- Tensor Train (TT) formats
- Neural Network parameterizations
```
