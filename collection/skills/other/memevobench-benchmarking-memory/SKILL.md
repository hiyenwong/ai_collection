# MemEvoBench: Benchmarking Memory MisEvolution in LLM Agents

**arXiv ID:** 2604.16150  
**Published:** 2026-04-18  
**Authors:** Weiwei Xie, Shaoxiong Guo, Fan Zhang  
**Categories:** cs.CL  
**Utility Score:** 0.98

## Abstract

Equipping Large Language Models (LLMs) with persistent memory enhances interaction continuity and personalization but introduces new safety risks. Specifically, contaminated or biased memory accumulation can trigger abnormal agent behaviors. Existing benchmarks focus on static memory retrieval but overlook the temporal dynamics of memory evolution.

## Key Contributions

1. **Memory MisEvolution**: Identifies risks from contaminated or biased memory accumulation
2. **Temporal Dynamics**: Benchmarks memory evolution over time, not just static retrieval
3. **Safety Evaluation**: Tests for abnormal behaviors triggered by memory issues

## Relevance to AI Agent Systems

- **Memory Management**: Core focus on persistent memory in LLM agents
- **Long-Horizon Tasks**: Addresses memory over extended interactions
- **Safety**: Critical safety implications for memory contamination
- **Tool Use**: Memory affects tool-using agent behavior
