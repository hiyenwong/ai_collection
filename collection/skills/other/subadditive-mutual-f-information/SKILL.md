# Subadditive Mutual f-Information

**Paper**: "On the Subadditivity of Mutual f-Information" — Abin & Gohari (CUHK), arXiv:2610.21231 (Oct 2026). Solves an open problem from Polyanskiy–Wu's *Information Theory: From Coding to Learning* (§7.8).

## Core Problem

Mutual f-information is `I~_f(X;Y) = D_f(p_XY ‖ p_X p_Y)`. For Shannon (f = x·log x), conditionally independent observations satisfy
`I(X; YZ) ≤ I(X;Y) + I(X;Z)` whenever Y→X→Z. Which other f-divergences keep this **subadditivity**? Known before: only f ∈ {x·log x, (x−1)·log x}.

## Theorem 1 — Sufficient Condition on g(x) = x²f″(x)

f is subadditive if:
1. `g″(x) < 0` for all x > 0 (strict concavity), and
2. ∃ constants η>0, ℓ∈ℝ with
   `g(x) + 2(g′(x) − η)² / (−g″(x)) ≤ 2η + (x−1)ℓ`  for all x > 0.

The proof reduces subadditivity to **concavity in q of the generalized variance functional**
`L_{u,p}(q) = E_p[ g(q/p · (u − E_q[u]))² ]`, then bounds the second variation by
`A₁ + 2γ̃²A₂ − 4γ̃²η ≤ 2γ̃²(θ₁ − 2η) ≤ 0` choosing θ₁ = 2η, where γ̃ = E_p[q/p].

NOTE: the condition excludes affine g (χ²-type f = (x−1)² family) — that exclusion is *necessary*: χ² mutual information violates subadditivity in ~50% of random Markov triples (MC verified).

## Corollary 1 — Constructor

Pick any positive concave s with s″<0 and `K_s(x) = s(x) + 2s′(x)²/(−s″(x))` concave. For α ≥ K_s(1), take g(x) = αx + s(x), (η,ℓ) = (α, K_s′(1) + α); then
`f(x) = αx·log x + ∫₁ˣ (x−t) s(t)/t² dt`  (normalizing f(1)=0)
is subadditive. Verified exact: x²f″ = αx + s(x) by Leibniz (err < 1e-6).

## Explicit Subadditive Families (Example 1)

- `f(x) = x·log x + (2a/3)(√x − 1)²`, a ∈ [0,1]
- `f(x) = x·log x + (5/6)(1 − (x−1)/log x)` (from uniform mixture over γ∈(0,1))
- `f(x) = 2x·log x − (x+1)·log((x+1)/2)` (s(x)=x/(x+1), K_s ≡ 1, α=1)
- `f(x) = x·log x + ¼∫₁ˣ (x−t)·log(1+t)/t² dt`

Positive mixtures of subadditive generators stay subadditive (cone property).

## Variational (G,f)-Information — Theorems 3/4

Second framework: `I_{G,f}(X;Y) = min_{q_Y} Σ_x p(x) G(D_f(p_{Y|X=x} ‖ q_Y))`. Under mild assumptions, information-subadditivity ⟺ divergence-subadditivity of D_{G,f} = G∘D_f over products (Thm 2 of [4]).

Key mechanism (Lemma 5, comparison inequality): if `G⁻¹(G(a)+G(b))` is separately concave then
`G⁻¹(G(a)+G(b)) ≥ a + b + γab` with `γ = [G⁻¹(2G(m)) − 2m]/m²` (positive ⟺ G concave; mirrored bound γ ≥ [2m − G⁻¹(2G(m))]/m² for convex G).

Sets `T_γ` / `T_γ⁻`: g with `x²g″(x) ∓ γg(α)g(x/α) ≤ 0 ∀x,α>0`. If x²f″ ∈ T_γ with γ ≤ [G⁻¹(2G(D_m(f))) − 2D_m(f)]/D_m(f)² (concave G), or ∈ T_γ⁻ with the mirrored bound (convex G), then (G,f) is divergence-subadditive. G generated by `G(x) = ∫₀ˣ dt/u(t)` for concave u; examples beyond the classical {x, log(1+x), −log(1−x)} include G(x)=x^p (p≤1) with non-concave generators like `ℓ_ε(x) = √x(1+ε·cos(log x))`, and a non-convex/non-concave G (Example 4: G(x)=½log(3(1+x)/(3−x))).

## Reusable Recipe — Designing a Subadditive Generalized Information Measure

1. **Choose the form**: direct `I~_f` (evaluated at true marginals, symmetric) vs variational `I_{G,f}` (optimizes auxiliary q_Y, generally asymmetric).
2. **Direct form**: pick concave s, verify K_s concave, set α ≥ K_s(1), integrate the Corollary-1 formula. Sanity-check the differential condition (3) numerically on a log grid of x.
3. **Variational form**: pick G via u(t) (e.g. x^p), compute the γ-range from D_m(f) = f(0) + lim_{t→∞} f(t)/t, pick g ∈ T_γ (or T_γ⁻) via parametric families; γ chosen to make all constraints simultaneously feasible (Examples 2–3 solve the feasibility inequalities for ε).
4. **MC sanity check**: sample thousands of random Markov triples Y→X→Z (Dirichlet priors over p_X, p_{Y|X}, p_{Z|X}); assert I~_f(X;YZ) ≤ I~_f(X;Y)+I~_f(X;Z) never violates (tolerance 1e-10); include χ² as a negative control (it must violate).
5. **Mixtures**: combine known subadditive generators with non-negative weights — closure under positive mixtures.

## Pitfalls (from numerical verification)

- **Finite-difference g on x²-scale is noisy**: derive f″ analytically or use high-order stencils; naive central differences on x²f″ produce O(1) errors at moderate x.
- **D_f convention**: paper uses `D_f(p‖q) = Σ q·f(p/q)` — implementing Σ p·f(q/p) inverts the ratio and breaks every check silently (first MC run 'failed' purely from this).
- **χ² exclusion is real**: f=(x−1)² (g=2, affine) violates subadditivity in ~1513/3000 random triples, max gap ≈ 0.3 — the g″<0 requirement is not cosmetic.
- **ℓ = α + K_s′(1)**, not 2α: for s(x)=x/(x+1), K_s ≡ 1 so ℓ = α = 1 and condition (3) holds with equality (margin 2.8e-14) — tight cases sit exactly on the boundary.
- **Example 2 generators are non-concave**: ℓ_ε(x)=√x(1+ε·cos(log x)) oscillates — membership in T_γ is what matters, not concavity of g itself.
- **Scale families by γ**: D_{G(γ·),f} = D_{G,γf} — scaling f rescales γ membership sets; use this to move a candidate generator into the feasible γ window.

## Quantum Connection

f-divergence generalizations connect to quantum f-divergences (Beigi–Hirche–Tomamichel, arXiv:2501.03799) and tensorization questions; the comparison-inequality mechanism (Lemma 5) is the classical shadow of transform-based quantum divergence chains (Petz/Rényi). Useful when selecting classical surrogates in quantum-entropy inequalities, and when checking whether a generalized (Sandwiched/Rényi-type) mutual information inherits chain-rule-like bounds.
