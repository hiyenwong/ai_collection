# Mersenne numbers and the doubling map

- **arXiv**: 2605.29130
- **Date**: 2026-05-29
- **Topic**: Number Theory, Statistics, Advanced Mathematics + Quantum

## Abstract

梅森数与倍角映射的动力学联系研究。通过角度倍角映射动力学框架，无需显式计算M(n)即可求梅森数的因子。提供替代Lucas-Lehmer检验的动力学方法证明大梅森数为合数。适用于大数素性检验、动力系统数论应用。

## Core Methodology

梅森数M(n)=2^n-1与倍角映射动力学联系：建立动力系统框架

无需显式计算的因子算法：通过动力学方法求梅森数因子

Lucas-Lehmer替代方案：基于动力学方法的素性检验

实际应用：证明M(2199023254451)为合数（约6.6×10^11位数）
