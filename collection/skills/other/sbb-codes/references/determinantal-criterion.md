# Determinantal-Ideal Criterion for SBB Codes

## Purpose

Detects whether a translation-invariant CSS subsystem code has nonlocal stabilizers. This is critical because:
- If nonlocal stabilizers exist → no finite-depth Clifford circuit can decouple gauge qubits
- If criterion excludes nonlocal stabilizers → gauge qubits can be cleanly separated

## Mathematical Foundation

Given a CSS subsystem code with gauge operators defined on a 2D toric lattice:

1. **Gauge Operator Commutation Matrix**: Construct the matrix C where C_{ij} encodes the commutation relation between gauge operator g_i and g_j.

2. **Polynomial Representation**: Express gauge operators as bivariate polynomials over F₂[x, x⁻¹, y, y⁻¹].

3. **Determinantal Ideal**: Compute the ideal generated by minors of the commutation matrix. The code has no nonlocal stabilizers iff this ideal satisfies certain algebraic properties.

## Procedure

### Step 1: Encode gauge operators as polynomials

For each gauge operator g_i, map its support on the lattice to a bivariate polynomial:
- Position (a, b) on lattice → term x^a y^b
- X-type and Z-type components tracked separately

### Step 2: Build commutation matrix

C_{ij}(x, y) = commutation phase between g_i at origin and g_j shifted by (x, y)

### Step 3: Compute determinantal ideal

Generate all k×k minors of C and compute the ideal they generate in F₂[x, x⁻¹, y, y⁻¹].

### Step 4: Check criterion

The criterion is satisfied (no nonlocal stabilizers) iff the determinantal ideal is the unit ideal (contains 1).

## Practical Application

For the SBB code examples:
- [[27,6,3]]: Criterion satisfied ✓
- [[75,10,5]]: Criterion satisfied ✓
- [[108,12,6]]: Criterion satisfied ✓

## Computational Notes

- Implemented using computer algebra systems (Macaulay2, Singular)
- Polynomial ring: F₂[x, x⁻¹, y, y⁻¹] / (x^L - 1, y^L - 1) for L×L torus
- Commutation matrix size depends on number of gauge generator types
