## QAC^0 Circuit Complexity

### Definition
QAC^0 = Constant-depth, polynomial-size quantum circuit families consisting of:
- Arbitrary single-qubit unitaries
- n-qubit generalized Toffoli gates

### Key Results (2604.07178)

**Equivalence Theorem**:
```
QAC^0 = 2D-QAC^0 (with quadratic size blow-up)
```

**Parity Lower Bounds**:
- 1D-QAC^0 requires nearly logarithmic depth for Parity
- Nearly linear depth for contiguous input encoding
- Proof methodology: restriction argument + light-cone argument

### Proof Techniques

**Light-Cone Argument**:
```
Gate G → Influence Region → Affected Qubits → Depth Constraint
```

**Restriction Argument**:
```
Full Circuit → Restrict Inputs → Simplified Circuit → Lower Bound Transfer
```

```python
import numpy as np
from scipy.linalg import expm

def compute_dla(generators):
    """Compute dynamical Lie algebra from generators."""
    dla = generators.copy()
    # Close under commutation
    while True:
        new_elements = []
        for g1 in dla:
            for g2 in dla:
                comm = g1 @ g2 - g2 @ g1
                if not in_span(comm, dla):
                    new_elements.append(comm)
        if not new_elements:
            break
        dla.extend(new_elements)
    return dla
```
