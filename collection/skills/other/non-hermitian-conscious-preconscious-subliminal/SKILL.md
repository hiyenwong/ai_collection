# Non-Hermitian Potential Well Formalism for Conscious–Preconscious–Subliminal Processing

Models the Global Neuronal Workspace (GNW) as a **complex-valued effective landscape** on a Hilbert space over a perceptual state space. Dynamics governed by a **nonlinear Schrödinger-type equation in imaginary time** with a non-Hermitian, non-normal Hamiltonian and nonlinear Lotka–Volterra term.

## Core Architecture

### Hamiltonian Decomposition
- **Hermitian part** → recognition via dissipative localization at minima of the GNW landscape
- **Anti-Hermitian part** → information broadcasting via spatial spreading across state space
- Complementary processes: localization vs spreading = recognition vs broadcasting

### Conscious Access Mechanism
- Conscious access = emergence of a **bound state**
- Two threshold conditions must be simultaneously exceeded:
  1. GNW landscape depth (stimulus strength)
  2. Degree of top-down attention

### Mathematical Framework
- Cloud function defined on Hilbert space over perceptual state space
- Combines holistic mental image structure with neural implementation
- Nonlinear Lotka–Volterra term preserves norm and enables spatially nonlocal interactions
- Reproduces subliminal–preconscious–conscious hierarchy

## Key Insights

1. **Unified framework**: sensory encoding and conscious access in same dynamical system
2. **Tractable dynamics**: analytical description of perception–consciousness continuum
3. **Threshold phenomenon**: conscious access as phase transition (bound state emergence)
4. **Complementary processes**: Hermitian (recognition) ↔ anti-Hermitian (broadcasting)
