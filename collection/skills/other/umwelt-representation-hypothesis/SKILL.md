# The Umwelt Representation Hypothesis: Rethinking Universality

## Overview

Challenges the **Universality Hypothesis** and proposes the **Umwelt Representation Hypothesis (URH)**: representational alignment arises from overlap in ecological constraints, not convergence toward a single global optimum.

## Key Contributions

1. **URH Framework**: Alignment reflects shared ecological pressures (task objectives, data distributions, architectural priors), not universal convergence
2. **Adaptive differences**: Representational differences between species, individuals, and ANNs are systematic and adaptive
3. **Reframing comparison**: Map clusters of alignment in ecological constraint space rather than searching for a single optimal world model

## Practical Implications

- Brain-AI alignment: more alignment ≠ better brain model
- Model selection: match ecological constraints to the neuroscience question
- Comparative neuroscience: use URH to understand why different representations emerge
