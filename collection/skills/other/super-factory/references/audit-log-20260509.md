## 手动审计发现的严重问题

### High: AgentResult.trace 序列化崩溃

`agents/protocol.py` 中 `trace` 字段声明为 `list[dict]`，但 `agents/base.py` 中 `_make_trace()` 返回 `list[Message]` (dataclass)。
`json.dumps(result.model_dump())` 会在执行时抛出 TypeError。

修复方案:
```python
# base.py _make_trace():
trace.append({"role": m.role, "content": m.content})
```

### High: _build_messages() 未实现

`BaseAgent._build_messages()` 是抽象方法，但所有四个域 agent 都没有实现。
`GenericAgent.execute()` 会直接抛出 `NotImplementedError`。

修复方案: 在 BaseAgent 中提供默认实现，或在每个域 agent 中实现。

### Medium: ModelRouter 缺少指数退避

`ModelRouter.get_provider()` 在 fallback chain 中直接切换到下一个 provider，
没有重试当前 provider 的指数退避逻辑。

### Medium: RateLimitError 处理不当

`OpenAICompatibleProvider` 捕获 `RateLimitError` 后直接 raise，
没有重试或退避。

### Low: ClaudeCLIRunner 超时硬编码

`ClaudeCLIRunner.run()` 使用硬编码 300s 超时，无法通过配置调整。
