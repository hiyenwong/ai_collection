# QUACOD + Dequantization Research Notes (2026-05-16)

## QUACOD Paper (arXiv:2605.14001)
- Nguyen et al. — "QUACOD: Quantum Optimization via Coordinate Descent for Scalable Drone Scheduling"
- Published 2026-05-13, quant-ph
- Outperforms SOTA quantum scheduling: 5x drones, 35x routes
- Hardware-efficient circuits validated for optimization subproblems
- Direct applicability to portfolio optimization, routing, feature selection

## Dequantization Paper (arXiv:2605.13979)
- Isogai, Yamasaki, Sonoda — "Winning Lottery Tickets in Neural Networks via a Quantum-Inspired Classical Algorithm"
- Published 2026-05-13, quant-ph + cs.LG + stat.ML
- Ridgelet transform enables O(poly(D)) classical sampling matching quantum quality
- Removes exponential dependency: exp(O(D)) → O(poly(D))
- Key implication: verify quantum advantage claims before hardware investment

## arXiv API Access Pattern
- Use `urllib.request` with ProxyHandler for proxy access
- Add User-Agent header to avoid 503 rate limiting
- Implement exponential backoff retry (5 retries recommended)
- Alternative: `httpx.Client(timeout=30.0)` with env vars `HTTP_PROXY`/`HTTPS_PROXY`
