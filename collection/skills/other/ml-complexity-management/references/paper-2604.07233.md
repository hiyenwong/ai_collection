# Paper: How Does Machine Learning Manage Complexity?

**arXiv**: 2604.07233
**Author**: Lance Fortnow
**Published**: 2026-04-08
**PDF**: papers/systems-engineering-2026-04-09/ml-complexity.pdf

## Abstract

We provide a computational complexity lens to understand the power of machine learning models, particularly their ability to model complex systems.

Machine learning models are often trained on data drawn from sampleable or more complex distributions, a far wider range of distributions than just computable ones. By focusing on computable distributions, machine learning models can better manage complexity via probability.

We abstract away from specific learning mechanisms, modeling machine learning as producing P/poly-computable distributions with polynomially-bounded max-entropy.

We illustrate how learning computable distributions models complexity by showing that if a machine learning model produces a distribution μ that minimizes error against the distribution generated by a cryptographic pseudorandom generator, then μ must be close to uniform.

## Key Contributions

1. **Complexity Framework**: P/poly-computable distributions + polynomially-bounded max-entropy
2. **Cryptographic Bound**: ML cannot learn pseudorandom generators (must approximate uniform)
3. **Distribution Focus**: Sampleable vs computable distributions distinction

## Implications for Complex Systems

- ML excels at sampleable distributions (observable/measurable systems)
- ML limited by computable distribution bounds
- Cryptographic security preserved against ML learning
- Complexity managed through probabilistic approximation

## Connections to Neuroscience

**Brain Networks**: 
- Brain dynamics likely sampleable (we can observe neural activity)
- Not purely computable (stochastic, emergent behavior)
- ML can model via learned probability distributions

**Complexity Bound**:
- Brain networks have bounded complexity (P/poly tractable)
- Emergent behavior still within ML's modeling capacity
- Stochasticity handled through probability estimation
