# Aethon: A Reference-Based Replication Primitive for Constant-Time Instantiation of Stateful AI Agents

**arXiv ID:** [2604.12129](http://arxiv.org/abs/2604.12129)
**Published:** 2026-04-13
**Authors:** Kyle Zhang, Akshay Kakkar
**Categories:** cs.DC, cs.AI
**Utility Score:** 1.00

## Abstract

Modern AI agents maintain complex state including memory, tool configurations, and conversation history. Current approaches to agent replication require serializing and deserializing entire state graphs, leading to instantiation times that scale with agent complexity. We introduce Aethon, a reference-based replication primitive that enables constant-time instantiation of stateful agents through structural sharing and copy-on-write semantics. Aethon reduces agent startup time from seconds to milliseconds, enabling elastic scaling of agent swarms and rapid failover in production deployments.
