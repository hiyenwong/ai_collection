# A Quantum Algorithm for Simulating Nonunitary Dynamics Governed by Nonautonomous Linear Ordinary Differential Equations

- **arXiv**: 2605.29052
- **Date**: 2026-05-29
- **Topic**: Number Theory, Statistics, Advanced Mathematics + Quantum

## Abstract

量子算法模拟非自治线性ODE的非幺正动力学。通过SVD分解将非幺正传播子写为酉算子之和，在量子硬件上直接执行膨胀，无需预知传播子闭式解。适用于开放量子系统、经济建模、非幺正动力学模拟。

## Core Methodology

非自治线性ODE的量子模拟：解决A(t)非斜对称时的非幺正动力学演化

SVD膨胀方案：将非幺正传播子分解为酉算子之和，在量子硬件上直接执行

无需预知传播子：避免经典计算每个时间步的传播子，纯量子实现

适用于开放量子系统和经济建模中的非幺正演化场景
