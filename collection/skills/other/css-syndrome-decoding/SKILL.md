# Css Syndrome Decoding

## Description
Factor-graph formulation of CSS quantum error correction syndrome decoding. Joint belief propagation on coupled Tanner graphs retains local channel correlation between Pauli error components. Provides unified view of joint BP and four-state BP equivalence for CSS code decoding.

## Core Methodology

### Framework
A Factor-Graph Formulation of CSS Syndrome Decoding: Joint BP and Four-State BP (arXiv:2605.05132)

### Key Principles
1. CSS syndrome decoding as binary factor graph with two coupled Tanner graphs
2. Joint BP retains local channel correlation between two Pauli error components
3. Joint BP and four-state BP are equivalent after relabeling and marginalization
