# SHADE: Shadow-based Data Erasure — 量子联邦遗忘 via 经典影子

## 一句话核心

量子态被测量即消耗、不可克隆 → 无法重放遗忘数据；但 QNN 的梯度与曲率是可观测量期望（对态线性）→ **训练时记录的经典影子可在任意后期参数下无偏估计它们** → 联邦牛顿一步修正即可擦除，且快照成本只随电路光锥（深度）而非量子比特数（宽度）指数增长。

## 激活关键词

- quantum federated unlearning, SHADE, classical shadows unlearning
- 量子联邦学习遗忘, 量子数据擦除, 影子快照
- QNN machine unlearning, quantum data privacy, no-cloning unlearning
- federated Newton correction, backward light cone shadows
- 量子传感网络数据撤回, sensor drift deletion

## 适用场景

| 场景 | 判据 |
|------|------|
| QFL 部署后节点撤回/传感器漂移/样本撤销同意 | 量子态已消耗、无法重放 |
| 量子传感网络需按时间窗删除漂移期数据 | 窗口删除（现有 stored-update 方法只能删整节点） |
| 需证明删除后模型与从未见过该数据的重训模型接近 | ‖θᵘ−θ^r‖ ≤ εᵘ 概率保证 |
| 经典数据联邦遗忘但数据留存成本敏感 | 光锥记录模式同样适用（观测算子局域化时） |

## 核心机制（三模块）

### 模块 1：光锥影子记录（节点侧，训练时）

每个状态 S 份副本留作记录。每份副本：每个量子比特 q 独立均匀抽取单比特 Clifford 旋转 V_{q,s}（X/Y/Z 三基映射到计算基的三个旋转之一），测得比特 b_{q,s}。快照：

```
ρ̂_s = ⨂_{q=1}^{n} ( 3 V†_{q,s} |b_{q,s}⟩⟨b_{q,s}| V_{q,s} − I )
```

满足 𝔼[ρ̂_s] = |ψ⟩⟨ψ|。**关键剪裁**：只存储后向光锥 Λ 内的量子比特数据（能通过 U 的门到达测量可观测量 O 支撑集的比特），光锥外因子迹为 1 不贡献 → 存储 3|Λ|·S 比特/状态（|Λ|=6, S=2000 时约 4.5 kB）。

**读出误差校准**：真实设备上读出噪声把单比特均值向最大混合态收缩，破坏反转。用同样方式测已知态 |0⟩^⊗n 校准每比特收缩因子，把因子 3 和 −I 替换为校准映射的逆。代价：方差最多放大收缩因子乘积平方倍，S 同比例增长。

### 模块 2：影子估计（节点侧，请求到达时）

参数位移规则把导数写成可观测量：

```
∂f/∂θ_j = ⟨ψ|A_j(θ)|ψ⟩,  A_j(θ) = ½[O(θ+π/2 e_j) − O(θ−π/2 e_j)]
∂²f/∂θ_j∂θ_j' = ⟨ψ|B_{jj'}(θ)|ψ⟩,  B_{jj'}: 四个 ±π/2 双移位算子、权重 ±¼
```

其中 O(θ) = U†(θ)OU(θ)。位移只改角度不改门布局 → A_j、B_{jj'} 都只作用在 Λ 上。

- 每状态用 median-of-means 对快照收缩 Tr[A ρ̂_s] 估计 f、∇f、∇²f
- 损失导数：∇ℓ = ℓ′∇f；∇²ℓ = ℓ″∇f∇fᵀ + ℓ′∇²f，**∇f∇fᵀ 的两个因子来自不相交的快照半区**（误差独立）
- 节点上传：遗忘梯度 ĝ_k^f = Σ_{forget} ∇̂ℓ（P 个数）+ 保留 Hessian Ĥ_k^r = Σ_{retain} ∇̂²ℓ（P(P+1)/2 个数）
- 每次收缩是 Λ 上的经典计算（指数于 |Λ|、无需量子硬件），P=24, S=2000 时每状态 ~1.25×10⁶ 次六比特收缩，完全可并行

### 模块 3：联邦牛顿修正（服务器侧）

θ* 极小化全量目标 → 保留集梯度 ∇L(θ*; D^r) = −g^f（负的全局遗忘梯度）→ 在保留曲率上做一步牛顿即撤销遗忘数据的拉力：

```
θᵘ = θ* + (Ĥ^r)^{-1} ĝ^f,   Ĥ^r = Σ_k Ĥ_k^r + μI（对称化，特征值下限抬到 μ）
```

广播 θᵘ，节点擦除 D^f 的快照（影子描述状态本身，残留可被用于重新学习遗忘数据 → 擦除是删除的一部分）。上传量与训练轮次同型（状态求和），对服务器不泄露比训练更多的单态信息。

**多请求处理**：同轮请求合并（遗忘集取并）。后续请求会在"由先前修正从快照算出的模型"上评估快照，破坏独立性 → 把每状态快照均分成组，每次请求用新组。

## 理论结果

**命题 1（无偏性）**：θ 独立于快照时，Tr[O(θ)ρ̂_s]、Tr[A_j(θ)ρ̂_s]、Tr[B_{jj'}(θ)ρ̂_s] 的快照均值是 f 及其一、二阶导数的无偏估计（任意纠缠态成立——单比特反转按比特独立连乘）。

**定理 1（光锥缩放）**：median-of-means 下，每状态

```
S = ⌈α · 4^|Λ|/ε² · log(|D|(P+1)²/δ)⌉
```

份快照使所有状态、所有 j,j′ 的 f、∂f/∂θ_j、∂²f/∂θ_j∂θ_j′ 估计以 ≥1−δ 概率进入 ε 邻域。**S 不依赖量子比特数 n**。每层 brickwork 电路给 Λ 至多加 2 比特 → S 乘至多 16。电路深度而非宽度决定记录成本。

**命题 2（修正误差界）**：L(·;D^r) 在包含 θ*、θ^r 的球上 κ-强凸、Hessian M-Lipschitz，且 ‖ĝ^f−g^f‖≤ε^g、‖Ĥ^r−H^r‖≤ε^H·κ 时：

```
‖θᵘ−θ^r‖ ≤ M‖g^f‖²/(2κ³)  +  ε^g/(κ−ε^H)  +  ε^H‖g^f‖/(κ(κ−ε^H))
```

第一项是单步牛顿的地板（不随 S 缩小），后两项对 ε 线性。平方损失下 ε^g ≤ 4√P|D^f|ε、ε^H ≤ 7P|D^r|ε。

## 实证锚点

- 设置：PennyLane 仿真 50 节点，n=8 比特横场 Ising 链基态相分类（γ∈[0.2,1.8]，铁磁/顺磁），P=24，O=Z₄，|Λ|=6，ℓ=(f−y)²/2，μ=0.01，60 轮；测试台 Jetson AGX 边缘板 ×3 节点 + Wi-Fi，Qiskit Aer + ibm_fez 156 比特噪声模型
- **遗忘精度匹配重训 0.5 分以内**（节点/窗口/样本三种删除全成立），修正 <0.2 s vs CR 精确牛顿 3226 s
- 样本删除下基线 QMU/SCRUB/CR 留在 ~52% 遗忘精度（vs 重训 29.6%——未真正遗忘）；SHADE 29.3 vs 重训 29.6
- 窗口/样本删除距离随 S 增长降 6–7×；节点删除停在 ~10⁻²（牛顿项主导，符合 Eq.10）
- n=8 与 n=12 所需快照同阶（验证光锥缩放）；到 20 比特节点/窗口删除至多 4.9×10³ 快照
- 零重放（基线 CR/QMU/SCRUB 都被授予了部署中不存在的新鲜副本仍输给 SHADE）；记录份额高到 90% 时测试精度仍 >95.7%
- MIA 成员推断攻击成功率 ~50%（随机水平）

## 与基线方法的本质区别

| 方法 | 需要重放？ | 能删子节点数据？ | 机制 |
|------|----------|----------------|------|
| FedRecovery (stored updates) | 否 | 否（只删整节点） | 从存储更新中扣除节点贡献 |
| QMU (gradient ascent) | 是 | 是 | 对遗忘态梯度上升 |
| SCRUB (distillation) | 是 | 是 | 蒸馏同时推开遗忘态输出 |
| CR (certified removal) | 是 | 是 | 精确牛顿修正（需精确导数） |
| **SHADE** | **否** | **是** | 影子估计导数 + 联邦牛顿 |

## 可复用的方法论模式

1. **"不可重放数据"的遗忘范式**：任何"训练后数据消失但导数可由训练时旁路记录线性重构"的学习系统（量子态、一次性传感流、受隐私约束的原始数据不可再访问），都可套用 [记录 → 任意后期参数估计 → 牛顿修正] 三段式。核心判据：**模型对该数据的梯度/曲率是否为对数据的线性泛函**（量子：期望值线性于态；经典：线性于样本指示）。
2. **局域化剪裁记录**：若被估计的泛函支撑于系统的局域（光锥/感受野/局部补丁），记录成本只随局域尺寸而非系统尺寸增长——先找"导数算子的支撑集"再定记录范围。
3. **median-of-means 样本预算**：4^m/ε² · log(估计总数/δ) 的统一形态（m=局域尺寸），处理重尾（随机 Pauli 测量方差界 4^m‖A‖²）。
4. **多请求独立性分组**：自适应使用记录数据的修正会破坏后续估计的独立性 → 一次性均分记录成组、逐请求消耗。
5. **隐私对齐擦除**：影子即状态的经典描述，删除必须连同影子一起擦除；上传聚合量与训练轮次同型可继承训练的隐私论证。

## 局限与诚实边界

- 牛顿地板项 M‖g^f‖²/(2κ³) 不随快照数缩小；遗忘集大或病态曲率时一步修正不足，需在新数据上续训
- 随机 Pauli 影子对局域内算子最优；深电路每层 ×16 成本仍指数增长（浅电路适用性最好）
- 读出误差需可校准（收缩因子不依赖被测态的假设）
- 强凸假设（μ 正则保证）；非凸 QNN 只有局部保证
- 实验规模 n≤20、浅电路；样本删除下距离约为 CR（拿到精确导数）的两倍
