# 动物决策的谐波光谱学 (Harmonic Spectroscopy of Animal Decisions)

来源: arXiv:2610.00990 — "Selection rules for the harmonic spectroscopy of animal decisions" (Salahshour, Max Planck Institute of Animal Behavior, Oct 2026)

## 核心论点

把光谱学原理搬到动物决策：线索(cue)几何配置不再是需要条件化的干扰变量，而是**测量仪器本身**。决策景观 H(φ,t) = -Σ_n K_n Re[F_n(t) e^{inφ}] 按衍射振幅分解：动物内在谱 K_n × 已知几何结构因子 F_n = Σ_j w_j e^{-inΘ_j}。实验者通过选择线索几何，预先决定实验"能看见哪些谐波"。

## 核心公式

1. **测量方程**：H(φ,t) = -Σ_{n≥1} K_n Re[F_n e^{inφ}]，其中 F_n = Σ_j w_j e^{-inΘ_j} (每谐波一个复数，由线索方位/权重算出)
2. **谱分解**：K_n(d) = J_int(d)·c_n(σ)·M_n(W)：交互增益 × 感觉核宽度滤波(高斯 e^{-n²σ²/2}) × 神经 form factor(活动 bump 的傅里叶系数，方 bump: sin(nW/2)/(nπ/4)，高斯 bump: e^{-n²σ_bump²/2})
3. **对称选择规则** (Proposition 1)：p 重对称线索阵列 ⟹ F_n = 0 除非 p|n。三线索 120° 时 n=1,2 被湮灭，响应从 n=3 开始；四线索 90° 从 n=4 开始
4. **凹口梳**：两线索间距 Δ 扫描时 F_n(Δ) = 2cos(nΔ/2)，在 Δ=180°/n 处湮灭第 n 谐波（90° 切断 n=2，60° 切断 n=3）；对称三线索凹口移至 Δ=4π/3n (n=2 在 120°)
5. **可检测性定律** (Eq.13)：z_n/z_1 = e^{-(n²-1)σ²/2}·[sin(nW/2)/sin(W/2)]·√(E|F_n|²/E|F_1|²) — 第三谐波需要 13-652 倍观测时间，解释了文献中普遍只报一谐波的"天花板"
6. **双通道估计**：occupancy 通道 (Gibbs 条件圆指数族 log p(φ|F) = Σκ_n Re[F_n e^{inφ}] − log Z, κ_n = Γ_n/D) vs drift 通道 (增量回归)。Proposition 2：弱响应极限下两通道渐近等方差 Var(Γ̂_n) = 4D/(T n² E|F_n|²)。一致性比 R_n = Γ_n/(Dκ_n) = 1 是无自由参数的证伪检验

## 关键实验结果

- **果蝇双目标**：二谐波系数在结构因子零点 90° 处变号 (实测 91.1° [81.9, 113.2])，collapse 斜率 κ₂=0.375±0.027 (R²=0.917)；κ₂/κ₁≈0.20-0.21 (最近两个距离层)
- **三目标队列**：凹口按几何预测移至 ~120° (实测 118.2° [110.2, 125.8])
- **神经罗盘验证** (EPG/椭球体)：2 重对称场景压制 |Z1| (10/10 只)；4 重对称压制对应矩 (10/10)；打破对称(同方位不同仰角)恢复一谐波锁定 (10/10)——选择规则读出在行为背后的神经表征里
- **bump 形状**：方 bump 预测 M₃ 负号但实测正 → 高斯 bump 胜出 (15/15 只)；对比度升高使 bump 变窄 σ=0.937→0.762 rad，宽度拟合到 M₂ 后预测 M₃ (0.093 vs 实测 0.110)
- **妥协→选择转变**：一谐波不可能产生局部双稳态分岔 (C(Δ)=2K₁cos(Δ/2)>0 ∀Δ<180°)；Δc≈100° 需 K₂/K₁≈0.93 但仅 K₃/K₁≈0.082——高谐波难测但经 n² 权重主导转变位置
- **鱼墙响应**：强偶谐波主导 (κ₂=-2.24, κ₄=1.03, 奇谐波≈0)——简单排斥规则(一谐波)漏掉主要结构
- **跨物种**：幼虫斑马鱼趋光 (一谐波 0.319, cue-frame vs lab-frame 4×差异)；小鼠头方向 (n=3 只动物不足以区分参照系)；衣藻(单细胞)分离扫描无凹口——测量可移植，谱不通用

## 诚实边界
- 二谐波系数**不跨几何传递** (三目标队列 collapse 失败 R²=-0.049)
- occupancy 通道要求准静态近似（几何变化慢于弛豫）；测得 τ₁=3.2-4.0s，D=0.22-0.29 rad²/s
- 绝对比率 Γ_n/(Dκ_n) 差 ~2 倍（增量相关低估 D 32-42%）
- WTA/漏积累/drift-diffusion 也能复现 κ₂ 幅度——系数本身不区分机制，凹口位置才区分

## 应用指南

- **实验设计**：收集数据前计算谱杠杆 E|F_n|²；对称阵列把响应起始推到 n=p；0 杠杆谐波报告为"不可测"而非"不存在"
- **行为分析**：用 occupancy 通道替代增量回归（增量回归有 s²/δt errors-in-variables 偏差，采样越密偏差越大；occupancy 对已知观测误差可去卷积）
- **环吸引子分析**：任何存在"方位变量在环上表征 + 线性感觉叠加 + 局部化活动 bump"的系统都可写为谐波谱，方法可直接移植（集体行为、趋化、活性物质）
- **机制鉴别**：不要用拟合系数大小鉴别机制；用几何预定的凹口位置 + 跨几何迁移检验

## 陷阱

- 无实验室框架块 (cos mΦ/sin mΦ) 时，房间各向异性会泄漏进 cue 谱（果蝇数据 lab-frame 二谐波 0.26）
- 位置→方位反转误差压制奇矩不影响偶矩——奇偶分析前先做方向矫正控制
- 三目标队列"名义中点"在动物自身坐标系常不在中间——镜像对称被破坏，cosine-only 模型错误设定
