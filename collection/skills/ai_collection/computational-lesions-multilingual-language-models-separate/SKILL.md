# Computational Lesions for Multilingual Brain Alignment

## Overview
Uses multilingual LLMs as controllable computational models to investigate whether language processing in the brain uses shared or language-specific neural mechanisms. The computational lesion approach provides insights that neuroimaging alone cannot achieve.

## Key Insight
By systematically lesioning different components of multilingual LLMs and measuring the resulting brain alignment changes, we can distinguish between shared and language-specific processing mechanisms in the human brain.

## Methodology
1. **Computational lesioning**: Selectively disable model components
2. **Brain alignment measurement**: Compare model representations with neuroimaging data
3. **Language comparison**: Analyze differences across languages
4. **Mechanism separation**: Distinguish shared vs. language-specific processing

## Applications
- Understanding multilingual brain organization
- Testing theories of language processing
