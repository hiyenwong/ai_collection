## Abstract
This paper extends recurrent Spiking Neural Networks (SNNs) by combining convolution operations with learnable axonal delays. The axonal delays are learned at runtime alongside network parameters, enabling efficient temporal pattern processing. The approach is designed for resource-constrained edge systems, providing a lightweight yet powerful framework for temporal signal processing.
