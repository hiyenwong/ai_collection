# Representation Use and Usability Framework

## Overview
A unified framework for understanding representation use and usability across philosophy and neuroscience, providing criteria for when neural states count as representations and how they are utilized.

## Source Paper
- **Title:** Use and usability: concepts of representation in philosophy, neuroscience, cognitive science, and computer science
- **arXiv:** 2604.13829v1
- **Authors:** Ben Baker, Richard D. Lange, Andrew Richmond, Nikolaus Kriegeskorte, Rosa Cao, Xaq Pitkow, Odelia Schwartz
- **Published:** 2026-04-15

## Core Concepts

### What Makes a Neural State a Representation?
Key criteria for neural representation:
1. **Aboutness/Intentionality:** The state is about something beyond itself
2. **Use:** The state is used by downstream mechanisms
3. **Usability:** The state can be accessed and utilized flexibly
4. **Content determination:** What the state represents

### Use vs. Usability Distinction
- **Use:** Actual deployment of representational content by mechanisms
- **Usability:** Potential for content access even when not currently used
- This distinction resolves debates about latent representations

### Framework for Analysis
1. Identify the putative representational vehicle (neural pattern)
2. Determine the content (what it represents)
3. Analyze use (how downstream mechanisms deploy it)
4. Assess usability (accessibility, flexibility, generalizability)
5. Evaluate content determination mechanism

## Applications
- Analyzing deep neural network representations
- Evaluating claims about neural coding
- Bridging philosophy and empirical neuroscience
- Assessing AI system understanding

## Key Questions
1. Does the neural state carry information about X?
2. Is this information used by downstream processes?
3. Can the information be accessed flexibly?
4. What determines the specific content?
