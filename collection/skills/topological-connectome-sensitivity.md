# Topological Sensitivity in Connectome-Constrained Networks

## Description

Connectome-constrained neural networks evaluated against sparse random controls to understand how biological graph topology improves learning efficiency. This methodology revisits claims through controlled flyvis-based studies using Drosophila connectome, naive self-loop-matched random graphs, and degree-preserving rewired null models.

## Core Methodology

### Connectome Constraints
- **Drosophila Connectome**: Complete neural wiring diagram
- **Random Controls**: Self-loop-matched random graphs
- **Rewired Nulls**: Degree-preserving rewired networks
- **Weak Controls**: Recovery from connectome-trained checkpoints
