# BCI Learning Core-Periphery Reorganization

**来源论文：** arXiv:2010.13459 - BCI learning induces core-periphery reorganization in M/EEG multiplex brain networks
**效用评分：** 0.98
**创建时间：** 2026-03-24 17:03
**期刊：** Journal of Neural Engineering

## 概述

研究 BCI 训练过程中脑网络的核心-边缘重组，采用多层网络方法整合 EEG 和 MEG 数据，发现体感区域整合增加与视觉处理区域整合减少的动态变化。

## 核心发现

```
BCI 训练引起的脑网络重组:

Alpha 波段:
┌─────────────────────────────────────────┐
│ 体感区域 → 整合度增加 ↑                  │
│ 视觉区域 → 整合度减少 ↓                  │
└─────────────────────────────────────────┘

Beta 波段:
┌─────────────────────────────────────────┐
│ 工作记忆区域 → 整合度减少 ↓              │
└─────────────────────────────────────────┘

预测指标:
- Alpha2 波段多层网络属性与未来 BCI 分数相关
- 体感/决策区域正相关
- 联合区域负相关
```
