# Quantum Hyperdimensional Computing (QHDC) — arXiv:2511.12664

## Core Insight
Hyperdimensional Computing (HDC), a brain-inspired model, maps natively onto quantum operations — not as a classical adaptation but as a quantum-native implementation.

## Five Core Mappings
1. **Hypervectors** → Quantum states (n-qubit states)
2. **Bundling** → Linear Combination of Unitaries (LCU) + Oblivious Amplitude Amplification (OAA)
3. **Binding** → Quantum phase oracles (phase kickback)
4. **Permutation** → Quantum Fourier Transform (QFT)
5. **Similarity** → Hadamard Test state fidelity measurement

## Hardware Validation
- Symbolic analogical reasoning tasks
- Supervised classification benchmarks
- Tested on 156-qubit IBM Heron r3 real hardware
- Comparison across classical, simulated, and real quantum execution

## Key Advantage
Resource-efficient direct mapping eliminates the need for complex classical-to-quantum adaptation layers that plague other quantum ML approaches.
