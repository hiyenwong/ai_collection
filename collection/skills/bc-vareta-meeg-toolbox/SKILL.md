# BC-VARETA - MEEG Source Connectivity Analysis Toolbox

**来源论文：** arXiv:1810.11212 - Third Generation MEEG Source Connectivity Analysis Toolbox (BC-VARETA 1.0) and Validation Benchmark
**效用评分：** 0.98

## 概述

BC-VARETA 1.0 是一个用于 MEEG (MEG/EEG) 源活动和连接性估计的工具箱，采用第三代非线性方法，实现超分辨率源重建和有效连接性估计。

## 核心特性

| 特性 | 描述 |
|------|------|
| **贝叶斯识别** | 频域线性动态系统建模 |
| **超分辨率** | 稀疏 Hermitian 源图模型迭代求解 |
| **高维估计** | 高效处理复杂连接性 |
| **解剖先验** | 灰质分割和概率掩码约束 |

## 工具箱组件

1. **源活动估计** - 超分辨率重建
2. **连接性分析** - 功能/有效连接
3. **验证基准** - 合成数据生成 + 性能评估
