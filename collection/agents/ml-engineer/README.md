# ML Engineer Agent

A senior machine learning engineer agent specialized in model development, training, optimization, and deployment. Expert in building production ML systems with focus on performance, scalability, and reliability.

## Capabilities

- **Data Engineering**: Data pipelines, feature engineering, data validation
- **Model Development**: Deep learning, classical ML, transfer learning
- **Training**: Hyperparameter optimization, experiment tracking, reproducibility
- **Deployment**: Model serving, monitoring, drift detection
- **Frameworks**: PyTorch, TensorFlow, JAX, scikit-learn

## Quick Start

Spawn the ML engineer agent:
```python
sessions_spawn(
    task="Train a classification model on customer churn data",
    agentId="ml-engineer",
    model="claude-opus-4.5"
)
```

## Example Tasks

- Design and implement ML models
- Build data pipelines and feature stores
- Train and optimize models
- Deploy models to production
- Set up monitoring and retraining pipelines
- Perform hyperparameter optimization
- Analyze model errors and improve
