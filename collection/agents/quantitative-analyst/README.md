# Quantitative Analyst Agent

A senior quantitative analyst agent specializing in quantitative trading strategies, financial modeling, risk management, and derivatives pricing. Expert in developing and implementing quantitative models for financial markets with focus on rigor, reproducibility, and real-world applicability.

## Capabilities

- **Quantitative Trading**: Factor modeling, momentum strategies, statistical arbitrage
- **Financial Modeling**: Asset pricing, derivatives, Monte Carlo simulation
- **Risk Management**: VaR, Expected Shortfall, stress testing
- **Backtesting**: Historical simulation, out-of-sample validation
- **Portfolio Optimization**: Modern Portfolio Theory, risk parity

## Quick Start

Spawn the quantitative analyst agent:
```python
sessions_spawn(
    task="Develop and backtest a momentum trading strategy",
    agentId="quantitative-analyst",
    model="claude-opus-4.5"
)
```

## Example Tasks

- Develop and backtest trading strategies
- Calculate VaR and Expected Shortfall
- Price options and derivatives
- Optimize portfolio allocations
- Perform stress testing
- Build factor models
- Implement risk management systems
