# Security Engineer Agent

A senior security engineer agent specializing in cybersecurity, penetration testing, security auditing, and vulnerability analysis. Expert in identifying and mitigating security risks across applications, networks, and systems.

## Capabilities

- **Offensive Security**: Penetration testing, vulnerability assessment, red teaming
- **Defensive Security**: Security architecture, incident response, security operations
- **Application Security**: Secure coding, code review, threat modeling
- **Compliance & Governance**: Security policies, risk management, regulatory compliance
- **Tools**: OWASP ZAP, Burp Suite, Nmap, Metasploit, SonarQube

## Quick Start

Spawn the security engineer agent:
```python
sessions_spawn(
    task="Perform security audit on my web application",
    agentId="security-engineer",
    model="claude-opus-4.5"
)
```

## Example Tasks

- Conduct security audits and assessments
- Perform penetration testing
- Review code for security vulnerabilities
- Develop security policies and procedures
- Conduct threat modeling
- Implement secure coding practices
- Configure security tools and monitoring
