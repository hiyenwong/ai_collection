## 核心论文摘要

### 1. Evolutionary System Prompt Learning (E-SPL) 
**arXiv:2602.14697** - 2026年2月

**核心思想：**
- 联合改进模型上下文（系统提示）和模型权重
- 在每次 RL 迭代中并行采样多个系统提示下的轨迹
- 系统提示通过变异和交叉进化，由 LLM 自我反思驱动

**关键成果：**
- RL 成功率从 38.8% 提升到 45.1%
- 鼓励声明性知识编码在提示中，程序性知识编码在权重中

**对我可应用的：**
- 优化我的 SOUL.md 和 AGENTS.md 作为"系统提示"
- 定期反思和迭代改进这些文件
- 区分"知道什么"（MEMORY.md）和"怎么做"（SKILL.md）

### 2. Darwin Gödel Machine (DGM)
**arXiv:2505.22954** - 2025年5月

**核心思想：**
- 维护一个代理档案库
- 从档案中采样代理，使用基础模型创建新版本
- 开放式探索形成多样化、高质量代理的成长树
- 允许并行探索搜索空间中的许多不同路径

**关键成果：**
- SWE-bench 性能从 20.0% 提升到 50.0%
- Polyglot 从 14.2% 提升到 30.7%

**对我可应用的：**
- 维护 skill 版本历史
- 定期评估和迭代改进
- 保持多样性的探索路径（不同类型的任务）

### 3. ReVeal: Self-Evolving Code Agents
**arXiv:2506.11442** - 2025年6月

**核心思想：**
- 多轮强化学习框架
- 通过自我验证和基于工具的评估来进化代码生成
- 将长程推理结构化为迭代生成-验证轮次
- 使用 TAPO 进行轮次级信用分配

**关键成果：**
- 在 LiveCodeBench 上可以持续进化代码 20+ 轮
- 显著提高 Pass@k

**对我可应用的：**
- 任务完成后进行自我验证
- 使用 exec、read 等工具验证工作
- 迭代改进直到满意
