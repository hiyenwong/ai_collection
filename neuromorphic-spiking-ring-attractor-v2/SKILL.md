# Neuromorphic Spiking Ring Attractor for Proprioceptive Joint-State Estimation

## Description

Continuous attractor networks provide a biologically inspired mechanism for encoding such variables, yet neuromorphic realizations have rarely addressed proprioceptive estimation under resource constraints.
