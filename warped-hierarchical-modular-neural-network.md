# Warped Hierarchical Modular Neural Network

## Description

A dynamical neural network model with hierarchical and modular structure derived by minimizing an energy function. The architecture features multiple subspaces spanned by neural parameters with different time constants, organized through layered internetworks with forward-backward subnet pairs.

This methodology enables complex neural dynamics modeling through geometrically-warped hierarchical structures inspired by biological neural organization principles.

## Core Concepts

### Energy-Based Architecture
- Energy function minimization drives network organization
- Two neuron types with distinct time constants
- Multiple hierarchical subspaces with layered connections
- Forward and backward subnetwork pairs

### Warped Space Organization
- Geometrically transformed parameter spaces
- Adjacent subspaces related through warping transformations
- Relaxation dynamics in transformed coordinates
- Modular decomposition of complex dynamics

## Technical Details

### Network Structure
| Component | Description |
|-----------|-------------|
| Energy Function | Drives self-organization |
| Fast Neurons | Rapid response dynamics |
| Slow Neurons | Sustained activity patterns |
| Internetworks | Layered connectivity |
| Forward Subnets | Feedforward processing |
| Backward Subnets | Feedback/modulatory pathways |

### Mathematical Framework
```
E = Σᵢ Eᵢ(wᵢ) + Σᵢⱼ Cᵢⱼ(wᵢ, wⱼ)

Where:
- Eᵢ: Local energy in subspace i
- Cᵢⱼ: Coupling between adjacent subspaces
- wᵢ: Neural parameters in subspace i
```
